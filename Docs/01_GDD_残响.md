# 《残响》RESIDUUM — 游戏设计文档 v1.0

> 第一人称写实恐怖取证游戏 · Unity 6 URP · 2 人团队 + Codex · 7 天垂直切片

---

## 0. 一句话定位

**你带着三件设备走进一栋不该进的房子，必须在理智耗尽前收集到足够证据、判定纠缠此地的究竟是什么，然后活着走出去。**

对标《恐鬼症》(Phasmophobia)，但把 24 种鬼、7 种证据、40 件道具的庞大系统压缩成一个**数学上闭合的最小推理核心**——这是本项目最重要的设计决策，也是 pitch 的核心卖点。

---

## 1. 设计哲学：为什么砍到 3×3

《恐鬼症》的乐趣不来自内容量，而来自三件事：

1. **信息不对称的恐惧** —— 你知道它在，但不知道它是什么、在哪
2. **有限工具下的演绎推理** —— 证据组合排除法
3. **风险与收益的拉扯** —— 多待一秒多一分证据，也多一分被猎杀的概率

这三点在最小规模下**完全成立**。所以垂直切片保留全部三点，只删内容量。

### 1.1 核心推理表（本作最优雅的设计）

3 种鬼 × 3 种证据，每种鬼持有 **恰好 2 项** 证据：

| 鬼种 | EMF-5 电磁读数 | 紫外线指纹 | 鬼影书写 |
|------|:---:|:---:|:---:|
| **怨灵 Spirit** | ✓ | ✓ | — |
| **幽影 Wraith** | ✓ | — | ✓ |
| **骚灵 Poltergeist** | — | ✓ | ✓ |

**为什么这个表是完美的**：三种"从 3 项中取 2 项"的组合恰好有 3 种，与 3 种鬼一一对应。这意味着：

- 玩家**必须**集齐 2 项证据才能判定，1 项永远不够（每项证据都被 2 种鬼共享）
- 集齐 2 项后判定**唯一确定**，不存在运气成分
- 排除法同样可用：确认某项证据**不存在**，也能推进推理

零冗余、零歧义、零运气。这是可以在 pitch 上讲 30 秒并让评审点头的设计。

### 1.2 行为差异化（让三种鬼有"人格"）

推理表决定"怎么判"，行为差异决定"怎么感觉不一样"：

| 鬼种 | 性格 | 独有行为 | 猎杀特征 |
|------|------|---------|---------|
| **怨灵 Spirit** | 迟缓、执拗 | 长时间停留在鬼房，脚步声沉重清晰 | 移动最慢 (1.6 m/s)，但猎杀持续最久 (30s)；被熏香驱散后 180s 内不再猎杀 |
| **幽影 Wraith** | 飘忽、无踪 | **不在地板留脚印**（玩家可用这点辅助判断）；会短距瞬移接近 | 移动 1.7 m/s，追击中每 6s 触发一次 1.5s 加速冲刺 |
| **骚灵 Poltergeist** | 暴躁、破坏 | 频繁抛掷房间内可交互物品，制造巨响 | 猎杀开始瞬间将周围所有物品同时抛飞；理智扣减速率 ×1.5 |

**给 Codex 的实现提示**：三种鬼的差异**全部通过 ScriptableObject 数据 + 一个策略接口**表达，不写 3 个独立 AI 类。详见技术文档。

## 2. 核心循环

```
        ┌──────────────────────────────────────────────┐
        │                                              │
   [准备区]  →  [进入·勘察]  →  [定位鬼房]  →  [取证]  │
   选3件道具      黑暗探索       温度骤降+EMF    3项证据 │
        ↑                            │              │   │
        │                            ↓              ↓   │
        │                      理智持续下降 ←────────┘   │
        │                            │                  │
        │                            ↓                  │
        │                    理智<50% → 猎杀触发         │
        │                            │                  │
        │                      [躲藏 / 逃跑]             │
        │                            │                  │
        └──── [撤离·提交判定] ← [判种·笔记本] ←─────────┘
                     │
                     ↓
                 [结算评分]
```

**单局时长目标：8–12 分钟。** 这是垂直切片的黄金长度——足够展示完整循环，短到可以在演示时跑完两遍。

## 3. 系统设计（含具体数值）

### 3.1 理智系统 Sanity

理智是本作的**节奏引擎**，控制恐惧曲线。

| 事件 | 理智变化 |
|------|---------|
| 起始值 | 100% |
| 处于黑暗中（无光源） | −0.12 %/秒 |
| 处于有灯光房间 | −0.06 %/秒 |
| 手持开启的手电筒 | 上述速率 ×0.5 |
| 目击鬼魂事件（Ghost Event） | −15%（一次性） |
| 被猎杀追击期间 | −0.5 %/秒 |
| 回到准备区（安全屋） | +1.0 %/秒，上限 100% |

**猎杀触发**：理智 < 50% 后，系统每 25 秒判定一次，触发概率 = `(50 − sanity) / 50`。
理智 50% → 0%；理智 25% → 50%；理智 0% → 100%（必定猎杀）。

> **设计意图**：玩家永远在算"我还能待多久"。这个焦虑本身就是游戏性。

### 3.2 猎杀 Hunt

- 持续 20–30 秒（按鬼种）
- 全场灯光闪烁失效，手电筒不可用（可听见电流杂音）
- 鬼可见、有实体、沿导航网格追踪最近玩家
- **视线丢失机制**：鬼失去玩家视野 3 秒后，切换为"最后已知位置 + 随机巡逻"
- **躲藏**：进入衣柜/床底后，若进入时鬼未看见你，则获得 `isHidden = true`，鬼无法直接定位；但鬼有 15% 概率随机检查藏匿点
- 猎杀结束后进入 25 秒冷却，期间必定不触发

### 3.3 证据系统 Evidence

| 证据 | 道具 | 采集方式 | 触发条件 |
|------|------|---------|---------|
| **EMF-5** | EMF 读数器 | 手持进入鬼活动区域，读数逐级跳到 5 格 | 鬼在附近发生互动事件后 8 秒内，且鬼种含此证据 |
| **紫外线指纹** | 紫外线手电 | 照射门把手 / 开关 / 窗台 | 鬼曾互动过该物体，且鬼种含此证据。指纹存在 60 秒后消失 |
| **鬼影书写** | 鬼影书（放置类） | 放置在鬼房地面，等待 | 每 30 秒判定一次，成功率 30%，鬼种含此证据时才可能成功 |

**采集即锁定**：每项证据一旦被采集，写入 `EvidenceManager` 并在笔记本 UI 中永久点亮。

### 3.4 道具 Items（4 件 + 1 个 UI）

| 道具 | 类型 | 功能 |
|------|------|------|
| 手电筒 | 常驻手持 | 主光源；F 键开关；**装备紫外线灯时自动熄灭**；猎杀期间强制闪烁失效 |
| EMF 读数器 | 手持 | 显示 1–5 格读数 + 蜂鸣音，5 格时高亮 |
| 紫外线手电 | 手持 | 紫光锥；照到指纹时指纹显现。**装备期间手电筒强制熄灭** —— 紫外荧光只在黑暗中可见，这是物理必然而非规则限制 |
| 鬼影书 | 可放置 | 放在地面，鬼可能在上面书写 |
| **判定笔记本** | UI (Tab 键) | 显示 3 项证据勾选状态 + 3 种鬼的推理表，可提交判定 |

**装备槽：3 个**。手电筒占 1 槽，玩家只能再带 2 件 → **必须做出取舍**，这是有意的设计压力。

#### 三件仪器的设计意图（重要）

它们不是「三种拿到证据的方式」，而是**三种不同的恐惧**。每一件都以不同方式把玩家推向危险：

| 仪器 | 强迫玩家做什么 | 代价 |
|------|--------------|------|
| **EMF 读数器** | 追着读数走 | 读数越高说明离鬼刚才的位置越近 —— **它把你拉向它** |
| **紫外线灯** | 停在原地仔细搜查 | 手电强制熄灭，房间全黑 —— **它拿走你的光** |
| **鬼影书** | 放下、离开、再回来 | 必须重返鬼房查看结果 —— **它逼你回去** |

行为模式分别是 **追踪 / 搜查 / 等待**，三者互不重叠。这是「为什么是这三件道具」的答案。

### 3.5 判定与结算

撤离到出口后提交判定：

| 结果 | 条件 | 评分 |
|------|------|------|
| 完美 | 判定正确 + 集齐 2 项证据 + 理智 > 30% | S |
| 成功 | 判定正确 | A |
| 幸存 | 判定错误但活着离开 | C |
| 失败 | 被猎杀致死 | F |

## 4. 地图设计

**单层郊区独栋住宅，约 200 ㎡，9 个可判定房间。**

```
 ┌─────────┬──────────┬─────────┐
 │  车库    │   厨房    │  餐厅   │
 │  Garage │  Kitchen │ Dining  │
 ├────┬────┴──┬───────┴────┬────┤
 │    │       走廊 Hallway  │    │   ← L形转角，制造"听得见看不见"
 │浴室 ├───────┴──┬─────────┤主卧 │
 │Bath│  卧室 A   │  卧室 B  │Master│
 ├────┴──────────┴─────────┴────┤
 │        客厅 Living Room        │
 ├───────────────────────────────┤
 │      玄关 Entrance  ←出口       │
 └───────────────────────────────┘
```

### 设计要点

- **鬼房随机**：每局从 9 个房间中随机选 1 个作为鬼房（Ghost Room），玩家必须靠温度和 EMF 找出来
- **藏匿点 6 个**：卧室A衣柜、卧室B衣柜、主卧衣柜、玄关储物柜、卧室A床底、主卧床底
  - 分布原则：**每个房间到最近藏匿点的距离 ≤ 12 米**，猎杀时玩家永远有一线生机，但需要跑
- **视线阻断**：走廊设计成 L 形，玄关到主卧无直线视野 → 脚步声先于视觉到达
- **可交互物件 ~20 个**：门（可开关，鬼会自己开）、抽屉、开关、水龙头。骚灵抛掷的就是这些
- **出口**：玄关大门，玩家随时可撤离（含中途放弃）

### 灯光方案

- 基调：**冷蓝月光**从窗户射入（Directional Light + 窗户 Light Cookie），室内几乎全黑
- 唯一暖光源：玩家手电筒（暖白 4200K，射程 12m，spot angle 45°）
- 每个房间有一盏可开关的顶灯，开灯会**降低理智消耗但增加被鬼注意的概率**（可选加分项）
- 后处理：Vignette + Film Grain + 轻微 Chromatic Aberration；猎杀时 Vignette 强度拉满 + 红移

### 鬼的视觉表现

不做高精度鬼模型（太贵）。方案：
- Mixamo 人形模型 + **半透明 Fresnel 边缘发光 Shader Graph 材质**
- 猎杀时才完全显形；平时只是"Ghost Event"中一闪而过的轮廓
- **看不清比看得清更可怕**，这既是省成本也是正确的恐怖设计

## 6. 音频设计（低成本高回报）

音频是恐怖游戏性价比最高的投入。三层：

1. **环境层**：持续的低频 drone（房屋呼吸声），根据理智值动态调整音量与低通截止频率
2. **事件层**：鬼的脚步（随距离衰减）、开门吱呀、物品掉落、远处敲击
3. **猎杀层**：心跳（随距离加速）、电流杂音、鬼的呼吸

**关键技巧**：`AudioDirector` 根据玩家理智值实时调整全局混音——理智越低，低频越重、混响越湿、心跳越明显。玩家会"感觉到"自己在崩溃。

## 7. 范围控制：明确不做什么

写下来是为了防止 7 天被吞掉：

| 不做 | 原因 |
|------|------|
| ❌ 多人联机 | 网络同步至少吃掉 3 天，会毁掉整个切片 |
| ❌ 语音识别（灵魂盒） | 依赖第三方 SDK，风险不可控 |
| ❌ 多张地图 | 一张打磨好的 > 三张灰盒 |
| ❌ 4 种以上鬼 / 证据 | 会破坏 3×3 推理表的数学完美性 |
| ❌ 存档 / 进度系统 | 切片不需要 |
| ❌ 主菜单美术 | 最后一天有时间再说 |
| ❌ 跳跃 | 能跳就能跳上家具，破坏关卡封闭性与 NavMesh 寻路 |

**如果进度超前**，按此顺序追加：① 温度计（第 4 项证据，需扩表到 4×4）② 第二张地图 ③ 熏香与十字架 ④ 本地双人分屏。

## 9. Pitch 三十秒版本（明天用）

> "《残响》是一款第一人称恐怖取证游戏。你进入一栋闹鬼的房子，用有限的三件设备收集证据，判断纠缠这里的是三种鬼中的哪一种，然后活着出去。
>
> 我们的核心设计是一张 3×3 的推理表——三种鬼，三种证据，每种鬼恰好持有两项。这意味着玩家必须集齐两项证据才能判定，而集齐两项后答案唯一。没有运气，全是演绎。
>
> 同时，你的理智会随着待在黑暗中持续下降，理智越低，被猎杀的概率越高。所以每多找一件证据，都是在拿命换。这个张力就是游戏的全部。
>
> 我们用 Unity 6 + URP，一周做一个 10 分钟可玩的垂直切片。"

**Pitch 时要展示的三样东西**：① 3×3 推理表（画在白板上，30 秒讲完，最有说服力）② 地图平面图 ③ 7 天排期表。
