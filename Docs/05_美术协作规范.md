# 《残响》美术岗位说明 & 协作规范

> 这份文档可以直接发给候选队友。
> 目标：让美术从 Day 1 就能全速开工，**完全不依赖主工程进度**。

---

## 一、你负责什么

**一句话**：《残响》是一款第一人称恐怖取证游戏（对标《恐鬼症》），你负责这款游戏"看起来是什么感觉"的全部。

Henry 负责所有玩法系统与代码（配合 Codex 生成），你负责视觉：**灯光、材质、后处理、场景陈设、UI 视觉、鬼的表现**。

**为什么这个岗位在这个项目里权重很高**：恐怖游戏 90% 的体验来自氛围，不来自机制。机制我们已经设计完并且会按计划做出来，但一栋"看起来很吓人的房子"和"看起来像 Unity 默认场景的房子"，是两个游戏。这部分完全由你决定。

---

## 二、独立赛道：你不需要等主工程

**关键约定：你在一个独立场景里工作，不碰主场景，不碰任何 .cs 文件。**

新建 `Assets/_Project/Scenes/_ArtLab.unity`，这是你的地盘。里面只放一段走廊 + 一个房间的白模，用来调氛围。你在这里产出的所有**设置**（Volume Profile、Lighting Settings、材质、Shader、预制体）最后会整体导入主场景 —— 所以不是练手，是真正的交付物。

### 你的七天

| Day | 目标 | 交付 |
|:---:|------|------|
| **1** | 定风格。收集 15–20 张参考图（恐鬼症、层层恐惧、逃生、P.T.），拉成一张 moodboard，定下色温、明暗对比、材质脏旧程度 | **风格板 1 张** |
| **2** | 在 `_ArtLab` 里调基础光照：冷蓝月光 Directional + 窗户 Light Cookie + 手电筒参数。目标是"几乎全黑，但看得清路" | **Lighting Settings + 效果图** |
| **3** | 后处理 Volume Profile：Vignette、Film Grain、Color Grading（冷色调 + 压暗高光）、轻微 Chromatic Aberration。再做一套"猎杀态"Profile（红移 + Vignette 拉满） | **两套 Volume Profile + 对比图** |
| **4** | 材质库：木地板、墙纸、瓷砖、金属、玻璃。用 Poly Haven 的 CC0 贴图，全部统一做旧处理（脏迹、掉漆、水渍） | **材质库 + 效果图** |
| **5** | 鬼的视觉：Mixamo 人形模型 + Fresnel 半透明 Shader Graph（边缘发光、身体半透）。目标是"看不清但知道那里有东西" | **鬼预制体** |
| **6** | **进主场景**：逐房间替换 Henry 的灰盒，导入你的光照与后处理设置，整体调优 | **完整场景** |
| **7** | 打磨 + UI 视觉（按 Codex 输出的 Canvas 层级说明填视觉） | **交付** |

> Day 1–5 你完全独立，Day 6 才与主工程汇合。这样两条线互不阻塞。

## 三、灰盒契约（最重要的一条规则）

Henry 会用白盒搭出完整地图（9 个房间）。Day 6 你替换它们时，必须遵守：

1. **不删灰盒物体，只在它下面挂美术模型**，然后把灰盒的 MeshRenderer 关掉（不是删掉）
2. **绝不修改任何物体的 Transform**（位置、旋转、缩放）
3. **绝不修改或删除 Collider** —— 玩家和鬼的碰撞、寻路全靠它
4. **绝不修改带有脚本组件的物体的层级结构**
5. 替换完成后通知 Henry，由他**重新烘焙 NavMesh** 并跑一遍全流程

> 违反其中任何一条，鬼会开始穿墙或卡死，而这个 Bug 在 Day 6 出现是致命的。

**灰盒命名规范**（Henry 遵守，方便你识别）：
```
BLK_Room_Kitchen_Floor
BLK_Room_Kitchen_Wall_N / _S / _E / _W
BLK_Prop_Door_Kitchen
BLK_Hide_Closet_BedroomA        ← 藏匿点，交互物体，务必保留碰撞
```
前缀 `BLK_` = blockout。凡是 `BLK_` 开头的物体，视觉可换，物理不可动。

## 四、技术约束

| 项 | 要求 |
|----|------|
| 渲染管线 | **URP**（不是 Built-in，不是 HDRP）。导入的素材如果是 Built-in 材质，需用 Edit → Rendering → Materials → Convert 转换 |
| Unity 版本 | **Unity 6 (6000.0 LTS)**，与 Henry 完全一致 |
| 素材来源 | 只用免费/CC0：[Poly Haven](https://polyhaven.com/)（CC0，最推荐）、[Mixamo](https://www.mixamo.com/)、Unity Asset Store 免费区、[ambientCG](https://ambientcg.com/)（CC0） |
| 许可记录 | 每导入一个素材，在 `Docs/ASSET_LICENSES.md` 加一行：素材名 / 来源链接 / 协议。**这是评分加分项** |
| 素材存放 | 第三方素材一律放 `Assets/ThirdParty/`，你自己做的放 `Assets/_Project/Art/` |
| 性能 | 目标 60 fps。实时阴影只给手电筒和月光，房间顶灯用烘焙。超过 4 盏实时点光就要开始砍 |
| Git | 场景文件容易冲突：**同一时间只有一人编辑主场景**。Day 1–5 你只动 `_ArtLab.unity`，Day 6 提前和 Henry 约定时段 |

## 五、风格锁定

**Day 2 结束前必须定死风格，之后不再改。**

基调方向（可讨论，但 Day 2 后锁定）：
- **写实**，但接受"素材决定风格" —— 风格统一远比单件精度重要
- 冷蓝月光为环境基色，玩家手电（4200K 暖白）是唯一暖光源，形成强烈冷暖对比
- 室内几乎全黑，靠手电筒切割出可视范围 —— **看不见的部分才是恐怖的来源**
- 陈设方向：有人住过但突然离开的房子。碗还在水槽里，床铺是乱的，电视机没关

**反面参考**（不要做成这样）：明亮的、干净的、家具摆放整齐的、色彩饱和的。

## 六、鬼的视觉：省钱且更吓人的做法

不做高精度鬼模型。方案：

1. Mixamo 免费人形模型 + walk / run / idle 动画
2. Shader Graph 做半透明材质：Fresnel 边缘发光 + 主体 alpha 0.25 左右
3. **平时完全不显形**，只在两种时刻出现：
   - Ghost Event：显形 2 秒，一闪而过的轮廓
   - 猎杀：完全显形并追击
4. 配合手电筒的闪烁故障，玩家永远只能看到断续的片段

> 这不只是省成本。恐怖设计的基本原理是：**玩家自己脑补的形象，永远比你做出来的更可怕。**

## 七、每日同步

10 分钟站会，三个问题：昨天完成什么 / 今天做什么 / 有什么卡住。
**卡住超过 2 小时必须换方案或砍需求，不许硬扛。**

Day 5 结束时会有一次关键交接：Henry 交付"完整可玩的灰盒版本"，你交付"完整的光照 + 后处理 + 材质库"，Day 6 合并。
