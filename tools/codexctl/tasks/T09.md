## 目标

全项目最难的一个模块，预留半天，可能要迭代两三轮。**宁可少做也不要做错。**

一个 `GhostAI`，四状态有限状态机，全部行为差异由 `GhostDefinition`
这个 ScriptableObject 的数值驱动——**不写三个鬼类**。

## 要做的文件

只产出 `Assets/_Project/Scripts/Ghost/GhostAI.cs`，命名空间 `Residuum.Ghost`，
用 `UnityEngine.AI.NavMeshAgent`。

### 状态机

`enum GhostState { Idle, Roam, Interact, Hunt }` + `switch`，**不要引入任何第三方 FSM 框架**。
`public GhostState State { get; private set; }`。

**【Idle】** 停在鬼房内的随机点，停留 `[SerializeField]` 可调秒数范围（默认 `5`–`15`）。
到时后按 `[SerializeField]` 概率（默认 `30%`）转 Roam，否则转 Interact。

**【Roam】** 走到 `[SerializeField] private Transform[] _roamPoints` 里的随机一个。
**这个数组由人在场景里手摆**——不要去场景里搜房间，`Residuum.World` 的类一个都不许引用。
到达后停留可调秒数（默认 `3`–`8`），然后回鬼房转 Idle。速度用 `definition.walkSpeed`。
若 `definition.leavesFootprints` 为 true，每走可调距离（默认 `1.5` 米）在地面生成一个
`[SerializeField]` 脚印预制体，存活可调秒数（默认 `20`）后销毁。

**【Interact】** 在当前位置附近用 `Physics.OverlapSphere` 找带 `IInteractable` 的物体
（半径可调，默认 `2.5`），随机选一个：
- 调用 `GameEvents.RaiseGhostInteract(该物体位置)`
- 按可调概率（默认 `40%`）请求在该物体上生成指纹：
  **通过 `public UnityEngine.Events.UnityEvent<Transform> onFingerprintRequest` 暴露**，
  由人在 Inspector 里连到 `Fingerprint.SpawnAt`。**不要直接引用 `Residuum.Evidence` 的类**
- `definition.interactFrequency` 作为互动频率倍率（骚灵为 2.0）
- 完成后转回 Idle

**【Hunt】** 由外部调用 `public void EnterHunt(float duration)` 进入（调用方是 T10，不是你）。
- 速度切到 `definition.huntSpeed`
- 追击 `[SerializeField] private Transform _player`（由人注入，不要去场景里找）
- 视线检测每 `[SerializeField]` 可调秒数（默认 `0.25`）一次，见下方「视线检测」
- 丢失视线超过可调秒数（默认 `3`）后走向最后已知位置，到达后在附近随机游走
- **玩家躲藏时**（订阅 `OnHidingChanged` 维护的 bool 为 true）：不能直接锁定玩家，
  改为在最后已知位置附近游走；但每可调秒数（默认 `5`）有可调概率（默认 `15%`）
  强行走向玩家实际位置，模拟「检查藏匿点」
- 若 `definition.canSprintBurst`（幽影），每隔 `definition.sprintBurstInterval` 秒
  把 `agent.speed` 临时提升可调倍率（默认 `1.8`）持续可调秒数（默认 `1.5`）
- 与玩家距离小于可调值（默认 `1.2` 米）**且玩家未躲藏**时调用 `GameEvents.RaisePlayerCaught()`
- duration 到期调用 `GameEvents.RaiseHuntEnd()` 并回 Idle

### 视线检测（按这个做，不要只连一条线）

**不要**只从鬼中心到玩家中心打一条 `Linecast`——那样玩家蹲在半墙后要么完全可见
要么完全不可见，手感很假。改为向玩家身上的**三个采样点**各打一条：
`[SerializeField] private Transform[] _playerSightPoints`（人在 Inspector 里连头、胸、脚），
数组为空时回落到玩家 Transform 加两个可调的高度偏移。
**任意一点可见即判为有视线**，全部被挡才算丢失。
遮挡层用 `[SerializeField] private LayerMask _sightBlockMask`。

### NavMeshAgent 的硬性要求（这几条是这个任务最容易翻车的地方）

1. **绝不要在鬼身上加 `NavMeshObstacle`**。它会挖掉自己脚下的导航网格，
   agent 检测到自己不在网格上就会原地不动。
2. **不要每帧调 `SetDestination`**。`pathPending` 期间 Unity 会把速度清零，
   每帧调用会让鬼一直抽搐着走不动。只在**目标点变化超过可调阈值**（默认 `0.5` 米）
   或按可调间隔（默认 `0.2` 秒）时才调一次。
3. **必须检查 `SetDestination` 的返回值**。返回 false 说明目标点映射不到导航网格，
   要 `Debug.LogWarning` 指出是哪个状态、哪个坐标，**不要静默忽略**。
4. **每次设目标前检查 `agent.isOnNavMesh`**。为 false 时不要继续下发指令，
   打一条 warning 并保持当前状态，等下一次 tick 重试。
5. 提供 `public void WarpTo(Vector3 position)`，内部用 `agent.Warp()`。
   T15 回合开始时要把鬼传送进鬼房，**直接写 `transform.position` 会让 agent 与
   导航网格失去同步**，必须走 Warp。

### 其他

- `public GhostDefinition Definition { get; set; }`，由 GameManager 在回合开始时注入。
  为 null 时 `Debug.LogError` 并禁用自己，**不要用默认值硬撑**
- 平时 `Renderer` 关闭（不可见），只在 Hunt 状态与 GhostEvent 期间开启。
  渲染器用 `[SerializeField] private Renderer[] _renderers` 注入
- `public void TriggerGhostEvent()`：短暂显形可调秒数（默认 `2`）并调用
  `GameEvents.RaiseGhostEvent(transform.position)`，然后重新隐形
- `OnDrawGizmosSelected` 画出当前状态文字、当前目标点、视线射线，方便调试
- 协程的 `WaitForSeconds` 缓存为字段复用，不要在循环里 `new`
- `OnEnable` 订阅 / `OnDisable` 退订严格配对；`OnDisable` 停止所有协程

## 明确不要做的

- **不要做猎杀的触发判定与冷却** —— 那是 T10 `HuntController`，你只提供 `EnterHunt`
- **不要做开门 / 推门** —— 那是 T10 之后的事。本阶段鬼**过不去关着的门**，这是已知限制
- **不要做 `massThrowOnHunt` 的抛物实现** —— 读这个字段但本轮只用来调互动频率，
  抛飞物品需要物理与预制体，不在本轮范围
- **不要引用 `Residuum.World` 的任何类**（`RoomVolume` / `RoomManager` / `Door` 都不许），
  巡逻点走 `Transform[]`，可交互物走 `IInteractable`（它在 `Residuum.Core`）
- **不要引用 `Residuum.Evidence`** 的具体类，指纹走 `UnityEvent<Transform>`
- **不要引用 `Residuum.Player`**，玩家走 `[SerializeField] Transform`
- **不要**用 `FindAnyObjectByType` 去场景里找玩家或巡逻点，全部 Inspector 注入
- **不要自己启动 Unity**（见 AGENTS.md）
- 只产出这一个文件

## 验收标准

- 鬼在灰盒场景里巡逻：Idle 停鬼房、Roam 去巡逻点、Interact 时触发 `OnGhostInteract`
- 装备 EMF 靠近正在互动的鬼，读数跳动（说明事件真的发出去了）
- 手动调 `EnterHunt(20f)`：鬼切到 huntSpeed 直线追击玩家
- 玩家绕墙躲开视线超过 3 秒后，鬼走向最后已知位置并在附近游走
- 玩家距离小于 1.2 米时触发 `OnPlayerCaught`
- 20 秒后自动 `RaiseHuntEnd` 并回到 Idle
- **全程 Console 无 NavMesh 相关报错**，鬼不原地抽搐、不穿墙、不卡在门框
- 换一个 `GhostDefinition` 资产（改 huntSpeed / canSprintBurst），行为随之变化，
  **一行代码都不用改**
- 除 UnityEngine / UnityEngine.AI / UnityEngine.Events / System 外，
  只 `using Residuum.Core;`
- 所有数值 `[SerializeField]` + 中文 `[Tooltip]`，零硬编码魔法数
- 编译零错误
