## 目标

现在所有反馈都只在 Console 里。做完这个，玩家才能**看见**自己在玩什么：
理智、证据、准星提示、道具、电量、温度。

## 契约（已存在，不许改）

```
Assets/_Project/Scripts/Core/GameEvents.cs
Assets/_Project/Scripts/Evidence/EvidenceType.cs
Assets/_Project/Scripts/Core/RoundResult.cs
```

**十个事件已全部核对存在，HUD 完全靠它们驱动**——
不要引用 `Residuum.Player` / `Items` / `World` / `Ghost` 的任何类：

```csharp
GameEvents.OnSanityChanged(float)             // 理智条
GameEvents.OnEvidenceFound(EvidenceType)      // 证据清单打勾
GameEvents.OnInteractPromptChanged(string)    // 准星下方提示，null = 隐藏
GameEvents.OnSlotChanged(int, string)         // 当前道具槽与物品名
GameEvents.OnBatteryChanged(float)            // 手电电量 0–1
GameEvents.OnPlayerTemperatureChanged(float)  // 温度读数（摄氏度）
GameEvents.OnHuntStart(float) / OnHuntEnd     // 猎杀视觉强化
GameEvents.OnRoundStart / OnRoundEnd(RoundResult)  // 重置 / 收尾
```

`EvidenceType`：`None=0` / `EMF5=1` / `UVFingerprint=2` / `GhostWriting=3`。

## 要做的文件

只产出 `Assets/_Project/Scripts/UI/HUDController.cs`，命名空间 `Residuum.UI`。
uGUI + TextMeshPro。

**本任务只写脚本，不创建 Canvas 层级** —— 所有 UI 元件通过
`[SerializeField]` 由 Inspector 注入。缺失的元件要能**单独为空而不报错**
（只在首次用到时 `Debug.LogWarning` 一次），因为 Henry 会分批把元件连上。

### 六个显示元素，每个都能在 Inspector 单独关闭

用 `[SerializeField] private bool _showXxx = true;` 控制，方便截图演示时精简画面。

**1. 准星与交互提示**
- `[SerializeField] private Graphic _crosshair;` 常驻小点
- `[SerializeField] private TMPro.TextMeshProUGUI _promptLabel;`
- 订阅 `OnInteractPromptChanged`：非空则显示文案并让准星切到「高亮」颜色，
  null 则隐藏文案、准星恢复常态。两种颜色都做成 `[SerializeField]`

**2. 理智条**
- `[SerializeField] private UnityEngine.UI.Image _sanityFill;`（Filled 类型）
- 订阅 `OnSanityChanged`，`fillAmount = 当前 / 100`
- **颜色按数值渐变**：100% 白 → 50% 琥珀 → 0% 深红，三个颜色都 `[SerializeField]`，
  用两段 `Color.Lerp` 实现
- 低于 `[SerializeField]` 阈值（默认 `25`）时整条以可调周期（默认 `1.2` 秒）
  缓慢脉动透明度

**3. 证据清单**
- `[SerializeField] private TMPro.TextMeshProUGUI[] _evidenceLabels;`（长度 3）
- 三行固定文案（EMF-5 / 紫外线指纹 / 鬼影书写），中文名做成 `[SerializeField] string[]`
- 订阅 `OnEvidenceFound`：对应行切到「已发现」颜色并加前缀标记；
  未发现时用暗色。两种颜色 `[SerializeField]`
- 订阅 `OnRoundStart` 全部重置为未发现

**4. 当前道具与电量**
- `[SerializeField] private TMPro.TextMeshProUGUI _itemLabel;`
- `[SerializeField] private UnityEngine.UI.Image _batteryFill;`
- 订阅 `OnSlotChanged` 显示「槽位号 + 物品名」，物品名为 null 时显示「空」
- 订阅 `OnBatteryChanged` 更新 `fillAmount`；**电量条只在手持手电时显示**
  —— 判断方式：`OnBatteryChanged` 有更新且当前槽位物品名非空即显示，
  可用可调的隐藏延迟（默认 `2` 秒无更新则淡出）

**5. 温度读数**
- `[SerializeField] private TMPro.TextMeshProUGUI _temperatureLabel;`
- 订阅 `OnPlayerTemperatureChanged`，显示保留一位小数加「°C」
- 低于 `[SerializeField]` 阈值（默认 `2` 度）时切到冷色，提示接近鬼房

**6. 猎杀视觉**
- 订阅 `OnHuntStart` / `OnHuntEnd`
- 猎杀期间给一个 `[SerializeField] private Graphic _huntVignette;` 淡入，
  强度与脉动周期可调；结束淡出
- **不要**做后处理，只操作这一个 UI 图形

### 其他要求

- `OnEnable` 订阅 / `OnDisable` 退订**严格配对**，十个事件一个不漏
- 协程 `WaitForSeconds` 缓存复用，不要在循环里 `new`
- **不要每帧 `GetComponent`**，所有引用在 `Awake` 缓存
- 订阅 `OnRoundEnd(RoundResult)` 时隐藏 HUD（结算界面是 T16 的事）

## 验收标准

- 元件全部为空时进 Play **不报错**，只有一次性的警告
- 手动 `GameEvents.RaiseSanityChanged(80/40/10)`，理智条长度与颜色随之变化，
  低于 25 时脉动
- 手动 `RaiseEvidenceFound(EvidenceType.EMF5)`，清单对应行变为已发现
- 走到门前准星高亮并显示提示，走开恢复
- 按 1/2/3 切换道具，物品名变化；手电电量条随电量下降
- 走近鬼房温度读数下降并变冷色
- 手动 `RaiseHuntStart(20f)` 猎杀暗角淡入，`RaiseHuntEnd()` 淡出
- `OnRoundStart` 后证据清单重置
- 每个显示元素都能在 Inspector 单独关闭
- 除 UnityEngine / TMPro / System 外只 `using Residuum.Core;` 与
  `using Residuum.Evidence;`（后者仅取 `EvidenceType` 枚举）
- 所有数值与颜色 `[SerializeField]` + 中文 `[Tooltip]`
- 编译零错误
