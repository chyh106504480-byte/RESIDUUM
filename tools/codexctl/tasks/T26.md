## 目标

一个场景级组件，管两件恐怖氛围的事：

1. **猎杀期间全场灯光闪烁**——猎杀一开始灯就疯了，结束后恢复原样
2. **随机全场停电**——灯全灭、扣一笔理智，玩家必须自己跑去开关处重新开灯

停电这条把「开灯」变成一个要冒险出门的动作，这是它的设计价值所在。

## 契约已就位

```csharp
public static event Action<float> GameEvents.OnSanityPenalty;   // 扣除的点数
public static void GameEvents.RaiseSanityPenalty(float points);

public static event Action<bool> GameEvents.OnBlackoutChanged;  // true = 全灭
public static void GameEvents.RaiseBlackoutChanged(bool isBlackout);
```

**不要自己往 GameEvents.cs 加任何东西。**

## 只做一个文件

`Assets/_Project/Scripts/World/LightManager.cs`，命名空间 `Residuum.World`

## 要做的东西

```csharp
[Tooltip("本管理器管辖的全部灯光。留空时不工作并在 Awake 报错")]
[SerializeField] private Light[] _managedLights;

[Header("猎杀闪烁")]
[Tooltip("猎杀期间灯光闪烁的间隔秒数")]
[SerializeField] private float _flickerInterval = 0.12f;

[Tooltip("每次闪烁时，一盏灯保持亮着的概率")]
[SerializeField, Range(0f, 1f)] private float _flickerOnChance = 0.45f;

[Header("随机停电")]
[Tooltip("两次停电判定之间的间隔秒数")]
[SerializeField] private float _blackoutCheckInterval = 45f;

[Tooltip("每次判定触发停电的概率")]
[SerializeField, Range(0f, 1f)] private float _blackoutChance = 0.35f;

[Tooltip("停电时一次性扣除的理智点数")]
[SerializeField] private float _blackoutSanityPenalty = 10f;

[Tooltip("检查玩家是否已经把灯重新打开的间隔秒数")]
[SerializeField] private float _blackoutRecoveryCheckInterval = 1f;
```

### 一、猎杀闪烁

订阅 `GameEvents.OnHuntStart` / `OnHuntEnd`。

- 猎杀开始：**先把每盏灯当前的 `enabled` 记下来**，然后每
  `_flickerInterval` 秒给每盏灯按 `_flickerOnChance` 随机重设 `enabled`
- 猎杀结束：**把每盏灯恢复成猎杀开始前记录的那个状态**

**恢复这一步是硬要求。**玩家在猎杀前特意关掉的灯，猎杀结束后不能自己亮回来；
特意开着的也不能灭掉。闪烁是临时效果，不能改变玩家的选择。

停电期间触发猎杀时**不要闪烁**——灯本来就全灭了，闪烁会把灯点亮，
等于停电自己解除了。

### 二、随机停电

回合进行中，每 `_blackoutCheckInterval` 秒判定一次，命中 `_blackoutChance` 就：

1. 把 `_managedLights` 里每盏灯 `enabled = false`
2. `GameEvents.RaiseSanityPenalty(_blackoutSanityPenalty)`
3. `GameEvents.RaiseBlackoutChanged(true)`

**已经处于停电中就不要再判定**，否则会反复扣理智。

### 三、停电怎么结束

**不要去认识 `LightSwitch`。**每 `_blackoutRecoveryCheckInterval` 秒检查一次
`_managedLights` 里还有没有 `enabled` 为 true 的灯；有就说明玩家跑去
把某个开关打开了，于是 `RaiseBlackoutChanged(false)`，停电结束。

这样 `LightManager` 和 `LightSwitch` 互不认识，各管各的。

### 四、回合边界

订阅 `GameEvents.OnRoundStart`：解除停电状态、停掉闪烁、清空记录的灯光状态、
重置停电判定计时。**不要在这里强行开灯**——每个 `LightSwitch` 自己会按
`_startsOn` 恢复，两边都动会打架。

订阅 `GameEvents.OnRoundEnd`：停掉闪烁与停电判定。

`OnEnable` 订阅、`OnDisable` 取消订阅，两边都要写。
`OnDisable` 里若正在闪烁，要把灯恢复成记录的状态。

## 明确不要做的

- 不要改 `LightSwitch`、`PlayerSanity`、`GameManager`、`GhostAI`、
  `HuntController`、`PlayerController`
- 不要往 `GameEvents.cs` 或 `RoundResult.cs` 加任何东西
- 不要碰 `Light.intensity`、颜色、阴影设置，只开关 `enabled`——
  `PlayerSanity` 的光照探测判据是「附近有没有已启用的 Light」，
  改 intensity 骗不过它
- 不要用 `FindObjectsByType` 自动搜集场景里的灯，由 Inspector 注入
- 不要做音效（那是 T17）、不要做手电筒闪烁（手电归 Flashlight 管）
- 不要做电闸、保险丝这类额外机制
- 不要新建预制体或编辑器脚本

## 需要新事件怎么办

不要自己加。写在最终回复里说明签名与理由。本任务预期不需要。

## 验收标准

Henry 会把场景里的灯拖进 `_managedLights` 然后点：

1. 编译通过，`git diff` 只有新增的 `LightManager.cs`（及其 meta）
2. 进 Play，灯正常亮着，没有异常闪烁
3. 按 P 强制猎杀，**全场灯光立刻疯狂闪烁**，猎杀结束后全部恢复原状
4. 猎杀前手动关掉某一盏灯，触发猎杀再等它结束，**那一盏依然是关着的**
   （这条验「恢复到猎杀前的状态」，是本任务最容易写错的地方）
5. 把 `_blackoutCheckInterval` 临时调成 5 秒、`_blackoutChance` 调成 1，
   进 Play 五秒后全场灯灭，HUD 理智条一次性掉 10 点
6. 停电后走到 `LightSwitch` 按 E 开灯，一秒内停电状态解除
   （可以临时在 `OnBlackoutChanged` 上挂个 Debug.Log 观察）
7. 停电期间不会反复扣理智——盯着理智条看十秒，只掉了一次
8. 停电期间按 P 触发猎杀，灯**不会**因为闪烁而亮起来
9. 按 F10 结束回合再开新一局，灯恢复正常、停电状态清除
