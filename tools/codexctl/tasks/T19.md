## 目标

一个编辑器菜单命令，在当前场景里把 HUD 与结算界面的整套 UI 层级建出来，
并把 `HUDController` / `ResultScreenUI` 上的每一个 `[SerializeField]`
界面引用连好。

**为什么必须做这个**：`HUDController` 有 8 个界面引用、`ResultScreenUI`
有 5 个，全靠手拖既慢又容易连错，而且连错了不会报错、只会静默不显示。
项目里 `PlayerRigBuilder` / `GhostSetupBuilder` / `RoundSetupBuilder`
已经是这个路子，照抄它们的结构。

## 要做的文件

**只做这一个**：`Assets/_Project/Scripts/UI/Editor/UISetupBuilder.cs`

放在 `Editor/` 目录下，用 `#if UNITY_EDITOR` 或依靠 Editor 文件夹的
特殊语义都可以，按项目里现有编辑器工具的做法来。

菜单路径：`Residuum/搭建 HUD 与结算界面`

## 照抄现有工具的骨架

参照 `Assets/_Project/Scripts/Core/Editor/RoundSetupBuilder.cs`：

- 全程用 `Undo.RegisterCreatedObjectUndo` / `Undo.AddComponent` /
  `Undo.SetTransformParent`，并用 `Undo.SetCurrentGroupName` +
  `Undo.CollapseUndoOperations` 收成一步，中途失败 `RevertAllDownToGroup`
- 组件字段用 `SerializedObject` + `FindProperty` + `objectReferenceValue`
  赋值，最后 `ApplyModifiedPropertiesWithoutUndo`
- 结束时 `EditorSceneManager.MarkSceneDirty`，并 `Debug.Log` 一句
  「建好了什么」
- **幂等**：再跑一次不能建出第二套。先按名字找已有的根节点，
  找到就复用并重连引用，而不是新建

字段名请**直接读 `HUDController.cs` 与 `ResultScreenUI.cs` 源码确认**，
不要凭这份任务书猜。任何一个 `FindProperty` 返回 null 都要
`Debug.LogError` 报出字段名并中止，不能静默跳过。

## 要建的层级

### 前置：EventSystem

场景里没有 `EventSystem` 就建一个（`EventSystem` +
`InputSystemUIInputModule`，这个工程用的是新输入系统，
**不要用 `StandaloneInputModule`**，那个和 Input System 不兼容，
按钮会完全点不动且不报错）。已经有就不动。

### 字体

`TextMeshProUGUI` 没有字体资产会渲染成空白且不报错。
统一取 `TMPro.TMP_Settings.defaultFontAsset`；取到 null 时
`Debug.LogWarning` 提示「需要先导入 TMP Essentials」，但**不要中止**，
其余部分照建。

### 一、HUD 画布

根节点名 `HUD Canvas`：
- `Canvas`，`renderMode = ScreenSpaceOverlay`，`sortingOrder = 0`
- `CanvasScaler`，`ScaleWithScreenSize`，参考分辨率 `1920 x 1080`，
  `matchWidthOrHeight = 0.5`
- `GraphicRaycaster`
- 挂 `Residuum.UI.HUDController`

子节点（灰盒审美，不要花哨，全部用纯色 `Image` 与 TMP 文本）：

| 子节点 | 类型 | 位置 | 连到 |
|---|---|---|---|
| `Crosshair` | `Image` | 屏幕正中，8×8 px 白色方块 | `_crosshair` |
| `PromptLabel` | `TextMeshProUGUI` | 正中偏下 60px，居中对齐，字号 24 | `_promptLabel` |
| `SanityBar/Fill` | `Image`，`type = Filled`，`fillMethod = Horizontal` | 左下角，宽 260 高 18 | `_sanityFill` |
| `EvidenceList/Evidence0..2` | 三个 `TextMeshProUGUI` | 右上角竖排，右对齐，字号 20，行距 26px | `_evidenceLabels` 数组三项 |
| `ItemLabel` | `TextMeshProUGUI` | 右下角，右对齐，字号 22 | `_itemLabel` |
| `BatteryBar/Fill` | `Image`，`type = Filled`，`fillMethod = Horizontal` | 右下角 `ItemLabel` 上方，宽 160 高 10 | `_batteryFill` |
| `TemperatureLabel` | `TextMeshProUGUI` | 左下角理智条上方，左对齐，字号 20 | `_temperatureLabel` |
| `HuntVignette` | `Image` | 铺满全屏，纯红，初始 `alpha = 0`，**`raycastTarget = false`** | `_huntVignette` |

`HuntVignette` 必须放在所有子节点**最后**（盖在最上层），
且 `raycastTarget` 必须关掉，否则它会吃掉所有鼠标点击。
`Crosshair` 与所有纯展示文本的 `raycastTarget` 也一律关掉。

理智条与电量条各配一个深色底 `Image` 作为父节点背景，
`Fill` 是它的子节点、四边拉满。

### 二、结算画布

根节点名 `Result Canvas`：
- `Canvas`，`ScreenSpaceOverlay`，`sortingOrder = 100`（必须盖在 HUD 之上）
- `CanvasScaler` 同上
- `GraphicRaycaster`
- 挂 `Residuum.UI.ResultScreenUI`

子节点：

| 子节点 | 类型 | 说明 | 连到 |
|---|---|---|---|
| `Panel` | `Image` | 铺满全屏，黑色 `alpha = 0.85`，**建完后 `SetActive(false)`** | `_panelRoot` |
| `Panel/Grade` | `TextMeshProUGUI` | 居中偏上，字号 140，居中对齐 | `_gradeLabel` |
| `Panel/Title` | `TextMeshProUGUI` | `Grade` 下方，字号 36，居中 | `_titleLabel` |
| `Panel/Detail` | `TextMeshProUGUI` | `Title` 下方，字号 24，居中，允许多行 | `_detailLabel` |
| `Panel/RestartButton` | `Button` + 子 `TextMeshProUGUI` | 底部，240×56，按钮文字「再来一局」 | `_restartButton` |

**`_panelRoot` 必须是 `Panel` 而不是 `Result Canvas` 本身**，
因为 `ResultScreenUI` 组件挂在 `Result Canvas` 上、必须保持启用才收得到
`OnRoundSummary`。建完把 `Panel` 设为不激活。

## 连不上的引用怎么办

`_playerControllerBehaviour` 与 `onRestartRequested` 这两个不由本工具连——
前者要玩家物体、后者要 GameManager，都可能不在场景里。
建完在 `Debug.Log` 里明确列出「还需要手动连的两项」，写清楚拖什么到哪。

## 明确不要做的

- 不要改 `HUDController.cs`、`ResultScreenUI.cs`、`JournalUI.cs`
  的任何一行
- 不要建判定笔记本的界面（那是下一个任务）
- 不要新建预制体、材质、字体资产、`.asset` 文件
- 不要碰场景里已有的任何非 UI 物体
- 不要自动保存场景（`MarkSceneDirty` 即可，让 Henry 自己决定存不存）
- 不要新增 `GameEvents` 事件
- 不要做美术风格化：圆角、渐变、阴影、动画一个都不要

## 验收标准

1. 编译通过，`git diff` 只有新增的 `UISetupBuilder.cs`（及其 meta）
2. 在空场景与现有游戏场景里各跑一次菜单，都不报错
3. 跑完后 Hierarchy 里出现 `HUD Canvas` 与 `Result Canvas`，
   以及 `EventSystem`（原本没有的话）
4. 选中 `HUD Canvas`，`HUDController` 上 8 个界面引用全部非空，
   `_evidenceLabels` 数组长度为 3 且三项都非空
5. 选中 `Result Canvas`，`ResultScreenUI` 上 4 个界面引用与
   `_restartButton` 全部非空，`_panelRoot` 指向 `Panel` 而不是画布本身，
   且 `Panel` 在 Hierarchy 里是灰的（未激活）
6. 再跑一次同一个菜单命令，Hierarchy 里**不会**多出第二套画布
7. 按 Ctrl+Z 一次，整套 UI 全部撤销干净
8. 进 Play，准星、理智条、证据列表都能看到；用鼠标能点到结算面板的
   「再来一局」按钮（把 `Panel` 手动激活来验证）
9. 控制台最后一条日志列出了「还需要手动连的两项」
