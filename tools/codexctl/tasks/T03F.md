## 背景

两个问题的根都在 `Assets/InputSystem_Actions.inputactions`：

**一、T03 终审必修。** `ItemSlotSystem.cs:16-24` 把按键绑定硬编码成 C# 常量
（`<Keyboard>/1`、`<Mouse>/leftButton`…），运行时克隆 `Player/Previous` 等
现成 action 再覆盖绑定。这样改键要改代码，与「所有可调项归设计师在 Inspector 里调」
的铁律冲突，而且拿 `Previous` 同时当 1 号槽和 3 号槽的模板是随手凑的。

**这不怪你**：上一轮任务包写了「不要新建输入资产」，本意是别另起一个 asset 文件，
你理解成完全不许碰它，只好绕路。**本任务明确授权你修改这个资产文件。**

**二、`Interact` 挂着 Hold 交互器。** 玩家轻点 E 开门没有任何反应，必须按住
0.4 秒。Henry 决定改成轻点：开门是高频操作，猎杀逃跑时 0.4 秒延迟是致命的，
后面捡道具、放鬼影书、进藏匿点全走这个 action，都会带上这个延迟。

## 要改的文件

### 1. `Assets/InputSystem_Actions.inputactions`

**这是 JSON 资产，直接编辑，保持格式合法、缩进与现状一致。**

在 `Player` map 里：

- **`Interact`**：把 `"interactions": "Hold"` 改为 `"interactions": ""`。
  只改这一个字段，不要动它的绑定（`<Keyboard>/e` 与 `<Gamepad>/buttonNorth` 保留）
- **新增四个 Button 类型的 action**，`interactions` 与 `processors` 都留空字符串，
  各配一条 `Keyboard&Mouse` 组的绑定：

  | action 名 | 绑定 path |
  |---|---|
  | `Slot1` | `<Keyboard>/1` |
  | `Slot2` | `<Keyboard>/2` |
  | `Slot3` | `<Keyboard>/3` |
  | `ToggleFlashlight` | `<Keyboard>/f` |

  新 action 的 `id` 与新绑定的 `id` 各自生成一个**新的、互不重复的 GUID**，
  不要复用文件里已有的任何 id。绑定的 `action` 字段填对应 action 名，
  `isComposite` / `isPartOfComposite` 都为 false。

**不要**动 `Move / Look / Attack / Crouch / Jump / Previous / Next / Sprint`，
**不要**动 `UI` map 里的任何东西。

### 2. `Assets/_Project/Scripts/Items/ItemSlotSystem.cs`

- 删掉 `FirstSlotBindingPath` / `SecondSlotBindingPath` / `ThirdSlotBindingPath` /
  `PrimaryUseBindingPath` / `ScrollBindingPath` 这些**绑定路径常量**，
  以及 `CloneWithSingleBinding` 整个方法和它的调用
- 改为直接从注入的 `InputActionAsset` 里 `FindAction`：
  `Slot1` / `Slot2` / `Slot3` / `ToggleFlashlight`（若本类需要）/ `Attack`（左键使用）
  / `UI/ScrollWheel`（滚轮）
- 找不到任一 action 时 `Debug.LogError` 指明缺哪一个，并让组件安全退出，
  沿用文件现有的错误处理风格
- action 名保留为 `private const string`（那是资产里的名字，不是可调数值），
  但**绑定路径一个都不许留在代码里**
- 相应地清理 `DisposeInputActions`：现在用的是资产里的 action，不是克隆出来的实例，
  不需要 `Dispose`，但**启用/禁用仍要与 `OnEnable`/`OnDisable` 严格配对**，
  且只禁用本组件自己启用过的 action（沿用 `PlayerInteractor` 里
  `_interactActionEnabledHere` 那个写法）

## 明确不要做的

- **不要**改 `Flashlight.cs`。它的 F 键处理如果也克隆了绑定，本轮先不动，
  下一轮单独处理
- **不要**改 `PlayerController.cs` 或 `PlayerInteractor.cs`
- **不要**碰任何契约文件
- **不要**新建输入资产文件，只改现有那一个
- **不要**顺手调整任何现有 action 的绑定按键
- **不要自己启动 Unity**（见 AGENTS.md）
- 只产出上面两个文件的改动

## 需要新事件怎么办

本任务不需要新事件。

## 验收标准

- `InputSystem_Actions.inputactions` 是合法 JSON，Unity 能正常导入不报错
- `Player` map 里 `Interact` 的 `interactions` 为空字符串
- `Player` map 里多出 `Slot1 / Slot2 / Slot3 / ToggleFlashlight` 四个 Button action，
  分别绑到键盘 1 / 2 / 3 / F
- `ItemSlotSystem.cs` 里**搜不到任何 `<Keyboard>/` 或 `<Mouse>/` 字样**
- `ItemSlotSystem.cs` 里没有 `CloneWithSingleBinding`
- 编译零错误
