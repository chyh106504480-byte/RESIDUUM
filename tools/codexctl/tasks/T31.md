## 目标

把「开局四件道具就在手上」改成「**开局空手，道具摆在大堂，必须去拿**」。
外加丢弃动作，以及手电筒从编号槽里挪出来独占一个键。

## 现在是什么样

`ItemSlotSystem`（387 行）的架构是：

- `_slots` —— 三个 `IHoldable` 控制组件，**常驻挂在玩家身上**
- `_heldModels` —— 三个手持模型，挂在 `_handAnchor` 下面，用 `SetActive` 切显隐
- 槽位切换只是决定「哪个是当前」，组件本身一直在

**这个架构要保留。**不要改成「拾取时动态生成组件」，那会把整套
`IHoldable` 生命周期（`OnEquip` / `OnUnequip` / `OnPrimaryUse`）推倒重来。

## 改成什么样

### 一、槽位可以是空的

加一个「是否已持有」的状态，**三个槽开局全为未持有**。

- 未持有的槽：按对应数字键、滚轮切到它时**直接跳过**，不装备
- 三个槽全空时 `Current` 为 null，`_handAnchor` 下面什么都不显示
- **不需要空手模型**，什么都不显示就对了
- 广播 `GameEvents.RaiseSlotChanged` 时，空槽传 null 或空字符串作为物品名
  （`HUDController` 已有 `_emptyItemName = "空"` 会兜住）

### 二、手电筒挪出编号槽，独占一个键

三个编号槽留给三件证据道具（EMF、紫外线灯、鬼影书）——正好对上三种证据。

手电单独一路：

```csharp
[Header("手电筒")]
[Tooltip("手电筒的 IHoldable 控制组件，独立于三个编号槽")]
[SerializeField] private MonoBehaviour _flashlightSlot;

[Tooltip("手电筒的手持模型")]
[SerializeField] private GameObject _flashlightModel;

[Tooltip("装备/收起手电筒的按键")]
[SerializeField] private UnityEngine.InputSystem.Key _flashlightKey
    = UnityEngine.InputSystem.Key.T;
```

按 T 的行为：**已持有手电时，在「手电」与「上一个编号槽」之间来回切**。
没持有手电时按 T 无反应。

手电和编号槽**互斥**——同时只有一个 `Current`。

### 三、丢弃

```csharp
[Tooltip("丢弃当前手持道具的按键")]
[SerializeField] private UnityEngine.InputSystem.Key _dropKey
    = UnityEngine.InputSystem.Key.G;

[Tooltip("丢弃时道具出现在玩家前方多远，单位：米")]
[Min(0.3f)]
[SerializeField] private float _dropDistance = 1.2f;

[Tooltip("丢弃时道具出现的高度偏移，单位：米")]
[SerializeField] private float _dropHeightOffset = -0.3f;
```

按 G：当前有手持道具时，把它丢到玩家前方 `_dropDistance` 米处，
该槽变回未持有，`Current` 置空。

### 四、世界里的道具对象

```csharp
[Tooltip("三个编号槽各自在世界中的道具对象，长度必须为 3。" +
         "拾取时隐藏，丢弃时移到玩家前方再显示")]
[SerializeField] private GameObject[] _worldItems = new GameObject[3];

[Tooltip("手电筒在世界中的对象")]
[SerializeField] private GameObject _flashlightWorldItem;
```

**不要用预制体实例化。**每件道具全场只有一个，直接拿场景里那个对象
`SetActive` 切换 + 挪位置就行，省掉一整套预制体管理。

### 五、给拾取方用的公开接口

```csharp
/// <summary>拾取第 index 个编号槽的道具。已持有或索引越界返回 false。</summary>
public bool TryPickUpSlot(int index)

/// <summary>拾取手电筒。已持有返回 false。</summary>
public bool TryPickUpFlashlight()
```

拾取成功时：把对应的世界对象 `SetActive(false)`，该槽标记为已持有，
**并自动装备它**（玩家刚捡起来当然是拿在手上）。

### 六、回合边界

订阅 `GameEvents.OnRoundStart`：三个槽与手电全部变回未持有、
`Current` 置空、所有世界道具对象移回各自的初始位置并显示。

**初始位置要在 `Awake` 里记下来**，不能靠 `SetActive(true)` 就自动回去。

## 只改一个文件

`Assets/_Project/Scripts/Items/ItemSlotSystem.cs`

按键用 `UnityEngine.InputSystem.Keyboard.current` 直接读，
参照 `GameManager.HandleEditorShortcuts` 的写法（`wasPressedThisFrame`，
并对 `Keyboard.current == null` 做保护）。
**不要去改 `InputSystem_Actions.inputactions` 资产**——两个新键做成
`[SerializeField]` 更好改，Henry 已经改过一次键位了。

数字键 1/2/3、滚轮、左键使用这三条现有的 InputAction 逻辑**保持不变**，
只是要跳过未持有的槽。

## 明确不要做的

- 不要改 `Flashlight`、`EMFReader`、`UVLight`、`GhostWritingBook`
- 不要改 `IHoldable` 契约
- 不要往 `GameEvents.cs` 加任何东西——`OnSlotChanged` 已经够用
- 不要做世界道具的 `IInteractable`（那是下一个任务）
- 不要做丢弃时的物理抛掷、旋转、音效
- 不要做背包容量、重量、耐久
- 不要做空手模型
- 不要新建文件

## 验收标准

1. 编译通过，`git diff` 只有 `ItemSlotSystem.cs` 一个文件
2. 进 Play，**手上什么都没有**，HUD 物品名显示「空」，
   按 1/2/3 和滚轮都没反应
3. 在 Inspector 里手动调 `TryPickUpSlot(0)`（用 ContextMenu 或临时按键），
   第一件道具出现在手上，它在世界里的对象消失
4. 按 G 丢弃，道具出现在玩家前方约 1.2 米处，手上变空，HUD 显示「空」
5. 拿到两件道具后，按 1/2/3 只能在这两件之间切，第三个键没反应
6. 拾取手电后按 T 装备手电，再按 T 切回刚才那个编号槽
7. 没拿到手电时按 T 无反应
8. 手电在手上时按 1，切到编号槽，手电模型消失
9. 按 F10 结束回合再开新一局，手上重新变空，
   **所有道具回到各自的初始位置并显示出来**
10. 空手时按 G 无反应，不报错
