## 目标

`Assets/_Project/Scripts/Audio/` 现在是**空目录**，整个游戏没有一点声音。

本任务做一个音频管理器，管两件事：

1. **心跳**——鬼离得越近跳得越快越响；猎杀期间常驻
2. **氛围音效**——鬼现身、猎杀开始/结束、停电、发现证据

## 只做一个文件

`Assets/_Project/Scripts/Audio/AudioDirector.cs`，命名空间 `Residuum.Audio`

## 跨模块怎么处理

只允许 `using UnityEngine`、`using System.Collections`、
`using Residuum.Core`、`using Residuum.Evidence`。

需要鬼的位置来算距离，用 `Transform` 注入即可——`Transform` 是 UnityEngine
的类型，不涉及跨模块：

```csharp
[Tooltip("拖入场景里的 Ghost 物体")]
[SerializeField] private Transform _ghostTransform;

[Tooltip("拖入场景里的 Player 物体")]
[SerializeField] private Transform _playerTransform;
```

**不要 using `Residuum.Ghost` 或 `Residuum.Player`。**

## 一、心跳

```csharp
[Header("心跳")]
[Tooltip("心跳音源。建议 2D，Spatial Blend 设为 0")]
[SerializeField] private AudioSource _heartbeatSource;

[Tooltip("心跳音效")]
[SerializeField] private AudioClip _heartbeatClip;

[Tooltip("鬼在这个距离以内心跳达到最强，单位：米")]
[Min(0.1f)]
[SerializeField] private float _heartbeatNearDistance = 3f;

[Tooltip("鬼超过这个距离心跳完全停止，单位：米")]
[Min(0.1f)]
[SerializeField] private float _heartbeatFarDistance = 15f;

[Tooltip("最近距离时的音量与播放速率")]
[SerializeField] private float _heartbeatMaxVolume = 1f;
[SerializeField] private float _heartbeatMaxPitch = 1.6f;

[Tooltip("最远距离时的音量与播放速率")]
[SerializeField] private float _heartbeatMinVolume = 0f;
[SerializeField] private float _heartbeatMinPitch = 0.8f;

[Tooltip("两次距离采样之间的间隔秒数")]
[Min(0.02f)]
[SerializeField] private float _heartbeatUpdateInterval = 0.1f;

[Tooltip("音量与音调向目标值靠拢的速度，避免突变")]
[Min(0.01f)]
[SerializeField] private float _heartbeatLerpSpeed = 3f;
```

规则：

- **心跳只在这两种情况下响**：猎杀期间，或者鬼正在现身
  （收到 `OnGhostEvent` 后的一小段时间）。
  平时鬼在墙那边晃悠不应该有心跳，否则玩家全程都在听心跳，
  该紧张的时候反而不紧张了
- 按 `_heartbeatUpdateInterval` 采样一次鬼与玩家的距离，
  在 `_heartbeatNearDistance` 与 `_heartbeatFarDistance` 之间
  归一化，映射到音量与 pitch
- 音量与 pitch 都要用 `Mathf.Lerp` 向目标值平滑靠拢，**不要每次采样直接赋值**，
  否则会一跳一跳的
- 停止时音量渐弱到 0 再 `Stop()`，不要硬切

```csharp
[Tooltip("鬼现身后心跳持续的秒数")]
[Min(0f)]
[SerializeField] private float _manifestHeartbeatDuration = 4f;
```

## 二、氛围音效

一个 `[SerializeField] AudioSource _oneShotSource`（2D）配一组 clip，
每个都可以留空——**留空就跳过，不要报错**，灰盒阶段本来就没有素材：

| 事件 | 字段 |
|---|---|
| `OnGhostEvent` | `_ghostManifestClip` |
| `OnHuntStart` | `_huntStartClip` |
| `OnHuntEnd` | `_huntEndClip` |
| `OnBlackoutChanged(true)` | `_blackoutClip` |
| `OnEvidenceFound` | `_evidenceFoundClip` |
| `OnPlayerCaught` | `_playerCaughtClip` |
| `OnSanityCritical` | `_sanityCriticalClip` |

用 `PlayOneShot` 播，每个 clip 配一个 `[Range(0f,1f)] float` 音量。

## 三、回合边界

订阅 `GameEvents.OnRoundStart` 与 `OnRoundEnd`：停掉心跳、重置状态。
`OnEnable` 订阅、`OnDisable` 取消订阅，两边都要写。
`OnDisable` 里若心跳还在响也要停掉。

## Awake 校验

- `_heartbeatSource` 或 `_ghostTransform` 或 `_playerTransform` 为空 →
  `Debug.LogWarning` 点名字段，**心跳功能跳过但组件继续工作**
  （氛围音效不依赖它们）
- `_oneShotSource` 为空 → `Debug.LogWarning`，氛围音效跳过
- **不要 `enabled = false`**，缺素材是灰盒阶段的常态，不该让整个组件罢工

## 明确不要做的

- 不要改任何现有脚本
- 不要往 `GameEvents.cs` 加任何东西
- 不要在代码里 `new AudioSource` 或 `AddComponent`——音源由 Inspector 注入
- 不要做脚步声（`PlayerController` 已有 `OnFootstep` 事件，那是另一件事）
- 不要做音乐、混音器、AudioMixer 分组
- 不要引用任何具体音频资源路径
- 不要新建编辑器脚本或预制体

## 需要新事件怎么办

不要自己加。写在最终回复里说明签名与理由。本任务预期不需要。

## 验收标准

Henry 会随便找几个音效丢进去试：

1. 编译通过，`git diff` 只有新增的 `AudioDirector.cs`（及其 meta）
2. 建个空物体挂 `AudioDirector`，加两个 `AudioSource`（Spatial Blend 都设 0）
   分别拖进 `_heartbeatSource` 与 `_oneShotSource`
3. **所有 clip 都留空**时进 Play，控制台只有几条 Warning，没有报错，
   游戏正常跑
4. 只填 `_heartbeatClip`，按 P 猎杀：心跳响起，**走近鬼时越来越快越来越响，
   走远时变慢变轻**
5. 猎杀结束后心跳渐弱停止，不是硬切
6. 平时（非猎杀、鬼没现身）**完全没有心跳**
7. 把 `GhostAI` 的 `_manifestChance` 临时调成 1，鬼现身时心跳响起
   约 4 秒后停止
8. 填上 `_huntStartClip` 与 `_blackoutClip`，触发猎杀和停电时能听到
9. 按 F10 结束回合，心跳立刻停止
