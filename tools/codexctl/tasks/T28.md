## 目标

给 `LightManager` 加两件事：

1. **鬼现身时全场灯变红并闪烁**，现身结束后恢复原色
2. **猎杀开始时按概率二选一**：要么闪烁（现有行为），要么直接全场熄灭

## 只改一个文件

`Assets/_Project/Scripts/World/LightManager.cs`

现有的猎杀闪烁、随机停电、停电恢复检测**保持不变**，本任务只做增量。

## 一、鬼现身 → 红光闪烁

订阅 `GameEvents.OnGhostEvent(Vector3)`。鬼每次短暂现身都会广播它。

```csharp
[Header("鬼现身")]
[Tooltip("鬼现身时灯光变红并闪烁的持续秒数。应与 GhostAI 的显形秒数接近")]
[Min(0f)]
[SerializeField] private float _manifestEffectDuration = 2f;

[Tooltip("鬼现身时的灯光颜色")]
[SerializeField] private Color _manifestColor = new Color(0.85f, 0.1f, 0.1f, 1f);

[Tooltip("鬼现身时灯光闪烁的间隔秒数")]
[Min(0f)]
[SerializeField] private float _manifestFlickerInterval = 0.1f;

[Tooltip("每次闪烁时一盏灯保持亮着的概率")]
[Range(0f, 1f)]
[SerializeField] private float _manifestFlickerOnChance = 0.5f;
```

行为：

1. 收到 `OnGhostEvent` → 把每盏灯当前的 **`color` 和 `enabled` 都记下来**
2. 全部染成 `_manifestColor`，并按 `_manifestFlickerInterval` 闪烁
3. `_manifestEffectDuration` 秒后**把颜色和开关状态都恢复成记录的值**

**颜色可以改，`intensity` 绝对不要碰。**`PlayerSanity` 的光照探测判据是
「附近有没有已启用的 `Light`」，颜色不影响它；改 `intensity` 会让
「屋里黑漆漆但理智不掉」。

停电期间收到 `OnGhostEvent` **直接忽略**——灯本来就全灭，
染红加闪烁会把灯点亮，等于停电自己解除了。

猎杀期间收到 `OnGhostEvent` 也忽略，猎杀闪烁优先。

## 二、猎杀开始时二选一

```csharp
[Tooltip("猎杀开始时直接全场熄灭而不是闪烁的概率")]
[Range(0f, 1f)]
[SerializeField] private float _huntBlackoutChance = 0.3f;
```

`OnHuntStart` 时滚一次：

- 命中 → 走**现有的停电流程**（全灭 + `RaiseBlackoutChanged(true)`），
  **但不要扣理智**——猎杀本身已经在掉理智了，再叠一笔太狠
- 未命中 → 走现有的闪烁流程

猎杀期间进入的这次停电，`OnHuntEnd` 时**不要自动恢复**——
让玩家自己去开关处开灯，和随机停电一样。

现有的「检查还有没有灯亮着来解除停电」那套逻辑对这种停电同样适用，
不要另写一套。

## 三、三种效果的优先级，写死别自作主张

```
停电 > 猎杀闪烁 > 鬼现身红光
```

- 停电中：忽略猎杀闪烁与鬼现身
- 猎杀中：忽略鬼现身
- 三者的状态记录不能互相覆盖。**尤其是颜色快照**——鬼现身把颜色改红
  之后如果猎杀插进来，恢复时必须还能拿到最原始的颜色，
  不能恢复成红色

## 明确不要做的

- 不要改 `LightSwitch`、`GhostAI`、`PlayerSanity`、`HuntController`
- 不要往 `GameEvents.cs` 加任何东西
- 不要碰 `Light.intensity`、`range`、阴影设置
- 不要做音效（那是 T29）
- 不要改随机停电的既有参数与行为
- 不要新建文件

## 验收标准

1. 编译通过，`git diff` 只有 `LightManager.cs` 一个文件
2. 把 `GhostAI` 的 `_manifestChance` 临时调成 1、`_manifestCheckInterval`
   调成 3 秒，进 Play：鬼每次现身时**全场灯变红并闪烁**，两秒后
   **恢复成原来的颜色和原来的开关状态**
3. 现身前手动关掉某一盏灯，现身结束后**那一盏依然是关着的**
4. 连续触发五次现身，灯的颜色始终能回到最初的白色，不会越来越红
   （这条验颜色快照没有被自己污染）
5. 把 `_huntBlackoutChance` 调成 0，按 P 猎杀 → 灯闪烁
6. 调成 1，按 P 猎杀 → 全场直接熄灭，**理智不会额外掉 10 点**
7. 猎杀结束后灯保持熄灭，走到 `LightSwitch` 按 E 才恢复
8. 停电期间触发鬼现身，灯**不会**亮起来变红
9. 改回默认值（0.3）后连打几次猎杀，能看到两种表现都出现过
