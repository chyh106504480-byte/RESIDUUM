## 症状（阻断级）

**鬼永远不会在鬼影书上写字**，这项证据根本采集不到。
三种鬼里有两种持有它，抽到就凑不齐两项、判定不出来。

## 根因

`GhostWritingBook.OnUnequip`（约 144 行）：

```csharp
public void OnUnequip()
{
    _isEquipped = false;
    StopWritingChecks();
}
```

正常流程是：装备书 → 左键放到地上 → **切换到别的道具去干别的** →
过一会儿回来看有没有字。

而「切换到别的道具」会触发 `OnUnequip`，把写字计时停掉。
玩家放下书之后必然要切走，所以这个计时**永远撑不过几秒**。

`OnPrimaryUse` 里放置成功后调了 `StartWritingChecks()`，
紧接着就被 `OnUnequip` 停掉了。

## 只改一个文件

`Assets/_Project/Scripts/Evidence/GhostWritingBook.cs`

## 改法

`OnUnequip` 里**只有书还拿在手上时才停计时**。已经放在地上
（`IsPlaced` 为真）就保持计时继续跑：

```csharp
public void OnUnequip()
{
    _isEquipped = false;

    // 放在地上的书要继续等鬼写字——玩家放下它就是为了去干别的。
    if (!IsPlaced)
    {
        StopWritingChecks();
    }
}
```

**同时检查 `OnDisable` / `OnDestroy` / `HandleRoundStart` 里有没有
同类问题**：只要书处于 `IsPlaced` 状态，除了回合结束与被捡起，
不应该有任何路径停掉写字计时。

- `HandleRoundStart` 现有的写法看起来是对的（先停再按 `IsPlaced`
  重新开），**不要动它**
- `Interact`（被捡起）里停计时是对的，**不要动**

## 验收标准

1. 编译通过，`git diff` 只有 `GhostWritingBook.cs` 一个文件
2. 把 `_writingCheckInterval` 临时调成 `3`、`_writingChance` 调成 `1`
3. 进 Play，确认本局的鬼持有「鬼影书写」证据（按 K 看，
   或用 `GameManager` 的 `Forced Ghost` 指定骚灵/幽影）
4. 捡起书，按 `3` 装备，低头左键放到地上
5. **立刻按 `1` 切到 EMF**，走开去别的房间
6. 等约 3 秒后回来，书上出现字（若已配好两个材质），
   并且**能按 E 采集到鬼影书写证据**
7. 不切走、一直拿着书站着（书还在手上没放下），
   写字计时**不该**运行——手上的书不会自己出字
8. 捡回书之后计时停止；再放下重新开始
9. 按 F10 结束回合再开新一局，计时正确重置
