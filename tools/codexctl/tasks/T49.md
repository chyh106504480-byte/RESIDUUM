## 目标

点「开始游戏」不再直接跳进场景，改成：

```
点按钮 → 0.8 秒渐暗到全黑（中间显示「正在进入…」）
        → 黑屏时开始回合
        → 1.2 秒从黑渐亮到游戏画面
```

渐变期间屏蔽所有点击，防止连点开出两局。

## 要做两个文件

### 一、`Assets/_Project/Scripts/UI/ScreenFader.cs`（新建），命名空间 `Residuum.UI`

独立组件，挂在自己的画布上。**不要写进 `MainMenuUI`**——
结算界面的「再来一局」将来也会用它。

```csharp
[SerializeField] private CanvasGroup _fadeGroup;      // 整层的透明度
[SerializeField] private UnityEngine.UI.Image _fadeImage;
[SerializeField] private TMPro.TextMeshProUGUI _messageLabel;

[Tooltip("渐暗到全黑的秒数")]
[Min(0f)] [SerializeField] private float _fadeOutDuration = 0.8f;

[Tooltip("从全黑渐亮的秒数")]
[Min(0f)] [SerializeField] private float _fadeInDuration = 1.2f;

[Tooltip("全黑状态至少保持的秒数，让加载有个呼吸")]
[Min(0f)] [SerializeField] private float _holdDuration = 0.3f;

[Tooltip("黑屏时显示的文字")]
[SerializeField] private string _message = "正在进入…";
```

公开接口：

```csharp
/// <summary>渐暗到全黑 → 执行 onBlack → 渐亮。重复调用时忽略后来的。</summary>
public void FadeThrough(System.Action onBlack)
```

行为：

- 用协程做，`_fadeGroup.alpha` 从 0 到 1 再回 0
- **全黑期间调一次 `onBlack`**，然后等 `_holdDuration` 再开始渐亮
- 渐变期间 `_fadeGroup.blocksRaycasts = true`，结束后 `false`
- `_messageLabel` 只在渐暗开始时显示、渐亮开始时隐藏
- **正在渐变中再次调用直接忽略**，不要叠加协程
- 任一引用为 null 时：**不做渐变，直接调 `onBlack`**，
  并 `Debug.LogWarning` 点名字段。绝不能因为没连引用就让
  「开始游戏」失效
- `Awake` 里把 `alpha` 设为 0、`blocksRaycasts` 设为 false

不要用 `Time.timeScale`，不要碰 `Cursor`。

### 二、`Assets/_Project/Scripts/UI/MainMenuUI.cs`

加一个字段：

```csharp
[Tooltip("场景里的 ScreenFader。留空则不做过场，直接开始")]
[SerializeField] private ScreenFader _screenFader;
```

`HandleStartClicked` 改成：

- `_screenFader` 为 null → 保持现有行为（隐藏菜单、恢复
  PlayerController、Invoke），一行都不改
- 不为 null → 调 `_screenFader.FadeThrough(...)`，把**现有那三步
  原封不动**放进 `onBlack` 回调里

**顺序不能变**：隐藏菜单 → 恢复 PlayerController → `onStartRequested.Invoke()`。
结算界面要在回合结束后禁用 PlayerController，顺序反了玩家点不到按钮。

`MainMenuUI` 的其它任何一行都不许改。

## 明确不要做的

- 不要改 `ResultScreenUI`、`JournalUI`、`GameManager`、`PlayerController`
- 不要往 `GameEvents.cs` 加任何东西
- 不要碰 `Time.timeScale`
- 不要在代码里创建 UI 层级（搭建是下一步的事，本任务不做）
- 不要做进度条、百分比、Loading 动画
- 不要用第三方补间库

## 验收标准

Henry 会手动建一个画布：`Fade Canvas`（排序层 300，全场最高）
挂 `ScreenFader` + `CanvasGroup`，下面一个全屏黑色 `Image` 和一个
居中的 `TextMeshProUGUI`。

1. 编译通过，`git diff` 只有新增的 `ScreenFader.cs` 与
   `MainMenuUI.cs` 两个文件
2. 连好之后点「开始游戏」：画面 0.8 秒渐暗到全黑，
   黑屏中央出现「正在进入…」
3. 黑屏期间回合已经开始（HUD 在黑幕下面已经初始化）
4. 保持约 0.3 秒后，1.2 秒渐亮到游戏画面，文字消失
5. 渐变过程中**狂点鼠标不会开出第二局**
6. 把 `MainMenuUI._screenFader` 清空，点「开始游戏」行为和改动前
   完全一致（直接进游戏，无过场）
7. `ScreenFader` 上的引用故意留空一个，点「开始游戏」仍然能进游戏，
   控制台只有一条警告
8. 过场结束后玩家能正常移动、能点笔记本按钮（`blocksRaycasts` 已还原）
