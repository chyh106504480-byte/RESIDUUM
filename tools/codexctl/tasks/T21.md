## 目标

现在打开判定笔记本会**整个禁用 `PlayerController`**——移动、视角、光标一起停。
改成：**移动照常，鬼照常追你，只有视角交给鼠标去点界面。**

打开笔记本不再是安全屋。你在翻笔记本的时候会被鬼摸到。

## 契约已就位

```csharp
/// 参数：true 表示视角控制被界面接管
public static event Action<bool> GameEvents.OnLookSuspendedChanged;
public static void GameEvents.RaiseLookSuspendedChanged(bool isSuspended);
```

**不要自己往 `GameEvents.cs` 里加东西**，已经加好了。

## 为什么是「挂起视角」而不是「禁用组件」

光标现在只有 `PlayerController` 一个主人（`_lockCursorOnStart` 在
`OnEnable` / `OnDisable` 两处控制）。笔记本靠开关这个组件来间接借用
它的光标逻辑，代价是连移动一起停了。

改成事件之后，`PlayerController` 始终启用、光标依然只有它一个主人，
笔记本只负责说一句「我要接管视角了」。**不要让笔记本自己去写
`Cursor.lockState` 或 `Cursor.visible`**——两处同时写光标必然打架，
这个坑项目里已经踩过。

## 要改两个文件

### 一、`Assets/_Project/Scripts/Player/PlayerController.cs`

加一个私有字段 `_isLookSuspended`，在 `OnEnable` 订阅
`GameEvents.OnLookSuspendedChanged`、`OnDisable` 取消订阅
（放在已有的 `OnHidingChanged` 等订阅旁边）。

处理函数：

- 收到 `true`：`Cursor.lockState = CursorLockMode.None; Cursor.visible = true;`
- 收到 `false`：**只有 `_lockCursorOnStart` 为真时**才
  `Cursor.lockState = CursorLockMode.Locked; Cursor.visible = false;`
  （和 `OnEnable` 第 217 行那段保持一致，别无条件锁）

`Update` 里第 271 行的 `UpdateLook(deltaTime);` 改成挂起时跳过。
**只跳过 `UpdateLook` 这一个调用**：

- 移动照常读 `_moveAction`
- 冲刺、下蹲、体力、脚步声照常
- 重力与 `CharacterController.Move` 照常

`OnDisable` 里把 `_isLookSuspended` 复位成 `false`，
否则组件被禁用再启用会继承过期的挂起状态。

`PlayerController` 的其它任何一行都不许改。

### 二、`Assets/_Project/Scripts/UI/JournalUI.cs`

`SetJournalOpen`（约第 280 行）里这一段：

```csharp
if (_playerControllerBehaviour != null)
{
    _playerControllerBehaviour.enabled = !shouldOpen;
}
```

改成：

```csharp
GameEvents.RaiseLookSuspendedChanged(shouldOpen);
```

然后**把 `_playerControllerBehaviour` 字段整个删掉**，
连同它的 `[Tooltip]`、以及 `ValidateReferences` 里任何跟它有关的校验。
它已经没有用处了。

`JournalUI` 的其它任何一行都不许改——尤其是猎杀开始与回合结束时
强制关闭笔记本那两段要原样保留。

## 明确不要做的

- 不要改 `ResultScreenUI`。回合结束时冻住玩家是对的，那里继续用
  禁用 `PlayerController` 的老办法
- 不要改 `HuntController`、`GhostAI`、`GameManager`
- 不要往 `GameEvents.cs` 或 `RoundResult.cs` 加任何东西
- 不要让笔记本自己写 `Cursor.lockState` / `Cursor.visible`
- 不要做「猎杀期间也能开笔记本」——那两段强制关闭保持现状
- 不要新建文件
- 不要顺手改移动速度、灵敏度之类的数值

## 需要新事件怎么办

不要自己加。写在最终回复里说明签名与理由。本任务预期不需要。

## 验收标准

1. 编译通过，`git diff` 只有 `PlayerController.cs` 与 `JournalUI.cs` 两个文件
2. 按 Tab 打开笔记本：鼠标光标出现，**WASD 依然能走动**，
   人物照常有脚步声
3. 笔记本开着时移动鼠标，**视角不转**，只有光标在动，能点到排除按钮
4. 按 Tab 关闭：光标消失，视角恢复正常，能正常转头
5. 把 `PlayerController` 的 `Lock Cursor On Start` 取消勾选，
   关闭笔记本后光标**保持可见**（不会被强行锁回去）
6. 笔记本开着的时候按住 Shift 能冲刺、按 C 能下蹲
7. 笔记本开着时按 P 强制猎杀：笔记本自动关闭、视角立刻恢复、光标锁回去
8. 躲进衣柜（若已有藏匿点）再开笔记本，关掉后受限视角依然正常
9. 反复开关笔记本十次，光标状态与视角控制不会错乱
