## 目标

关键路径倒数第二环。决定**什么时候猎杀**——这是全游戏张力的来源：
理智越低越危险，玩家每多找一件证据都是在拿命换。

## 要做的文件

只产出 `Assets/_Project/Scripts/Ghost/HuntController.cs`，命名空间 `Residuum.Ghost`。

### 判定规则（照 GDD，数值全部 `[SerializeField]` 可调）

- `[SerializeField]` 判定间隔，默认 `25`（秒）
- `[SerializeField]` 猎杀阈值，默认 `50`
- 每隔判定间隔执行一次：
  - 当前理智 **≥ 阈值** → 不猎杀
  - 否则触发概率 = `(阈值 − 当前理智) / 阈值`，用 `Random.value` 判定
- 触发时：
  1. 取时长 = `_ghostAI.Definition.huntDuration`（Definition 为 null 时用
     `[SerializeField]` 兜底时长，默认 `25`，并 `Debug.LogWarning`）
  2. 调 `GameEvents.RaiseHuntStart(时长)`
  3. 调 `_ghostAI.EnterHunt(时长)`
  4. 进入冷却，冷却秒数取 `Definition.huntCooldown`，**冷却期间不再判定**
- 冷却从**猎杀结束时**开始计，不是从猎杀开始时——订阅 `GameEvents.OnHuntEnd`

### 必须有的

- `[SerializeField] private GhostAI _ghostAI;` 由 Inspector 注入，
  为空时 `Debug.LogError` 并禁用自己
- `public bool IsHunting { get; private set; }`
- `public void ForceHunt()` —— 演示与调试用，**无视理智、阈值和冷却**直接触发。
  这是 Henry 验收时唯一能手动触发猎杀的入口，必须能用
- 订阅 `GameEvents.OnRoundStart` 重置：理智缓存、冷却、计时器、`IsHunting`
- **Inspector 调试显示**：两个 `[SerializeField] private` 只读字段，在 `Update` 里更新
  —— 距下次判定还有几秒、当前触发概率。方便在 Play 模式下肉眼看状态
- `OnEnable` 订阅 / `OnDisable` 退订严格配对；协程在 `OnDisable` 停止；
  `WaitForSeconds` 缓存复用不要在循环里 `new`

## 验收标准

- 手动调 `GameEvents.RaiseSanityChanged(30f)` 把理智压到 30，
  25 秒内有较高概率（40%）触发猎杀，Console 能看到 `RaiseHuntStart` 的效果
- 理智 ≥ 50 时永不触发
- 猎杀期间 `IsHunting` 为 true，`RaiseHuntEnd` 后进入冷却，冷却期内不再判定
- `ForceHunt()` 无视一切条件立刻触发
- `OnRoundStart` 后所有状态归零，不跨局残留
- Inspector 里能看到「距下次判定秒数」与「当前触发概率」实时变化
- 除 UnityEngine / System 外只 `using Residuum.Core;`
- 所有数值 `[SerializeField]` + 中文 `[Tooltip]`，零硬编码魔法数
- 编译零错误
