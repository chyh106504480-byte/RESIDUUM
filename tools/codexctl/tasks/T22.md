## 症状

跑完 `Residuum/搭建判定笔记本`，笔记本能开（屏幕变暗，说明 Panel 激活了），
但**里面一个字都看不见**。同时 HUD 的理智条实际宽度约 880 像素，
而设计值是 260——**放大了约 3.4 倍**。

日志证明文本对象全都活着并在渲染（`Header0`、`GhostName0/1/2`、
`GhostEvidence1~8`、`Label` 都在报 LiberationSans 缺中文字形的警告），
只是渲染在屏幕外面。

## 根因（已定位，别再自己找）

`GetOrCreateUiChild`（`UISetupBuilder.cs:1230` 附近）：

```csharp
GameObject child = new GameObject(childName, typeof(RectTransform));
UnityEditor.Undo.RegisterCreatedObjectUndo(child, UndoLabel);
UnityEditor.Undo.SetTransformParent(child.transform, parent, UndoLabel);
return child;
```

`Undo.SetTransformParent` 等价于 `Transform.SetParent(parent)`，
默认 **`worldPositionStays = true`**，也就是保持世界变换。

画布带 `CanvasScaler`，`localScale` 会被压到 0.337 左右（取决于当前
Game 视图分辨率）。新建的物体世界缩放是 1，塞进画布时 Unity 为了保持
世界缩放不变，自动给它 `localScale = 1 / 0.337 ≈ 2.97`。

**本工具从头到尾没有重置过 `localScale`**（全文件搜 `localScale` 零命中）。

于是整套 UI 被放大约 3 倍。HUD 之所以看起来还凑合，是因为它的元素都锚在
四个角、绕自己 pivot 放大位置跑不远；笔记本的内容全挂在 `Panel` 下面，
`Panel` 自己被放大 3 倍，子物体就被从面板中心往外推 3 倍，**全部推出屏幕**。

## 只改一个文件

`Assets/_Project/Scripts/UI/Editor/UISetupBuilder.cs`

## 要改三处

### 一、`GetOrCreateUiChild` 重置局部变换（主因）

挂完父子关系后，把局部变换归零：

```csharp
child.transform.localScale = Vector3.one;
child.transform.localRotation = Quaternion.identity;
child.transform.localPosition = Vector3.zero;
```

**已存在的子物体也要走同一段重置逻辑。**现在的写法是找到已有节点就
提前 return，那样重跑菜单修不好上一次建坏的层级——而 Henry 场景里
已经有一整套建坏的 UI 了，他要靠重跑菜单来修。

改完之后，「找到已有的」和「新建的」两条路径都必须保证局部缩放是 1。

用 `Undo.RecordObject` 记录 Transform 再改，保证能撤销。

### 二、`Evidence` 容器漏配 RectTransform

`BuildJournalHierarchy` 里（`UISetupBuilder.cs:570` 附近）：

```csharp
GameObject evidence = GetOrCreateUiChild(panel.transform, EvidenceName);
SetSiblingIndex(evidence.transform, 0);
// ← 这里少了一句，直接进 for 循环建 Row 了
```

它默认是 anchor `(0,0)`、pivot `(0.5,0.5)`、size `(0,0)`，
也就是贴在面板**左下角**、零尺寸。三行证据相对它按 `(0,1)` 锚点
往下偏 160 像素，直接掉到屏幕下边缘外面。

给它加一句 `ConfigureStretchRect`，让它铺满 `Panel`，
这样下面三行的锚点计算才是相对整个面板的。

### 三、推理表偏移符号写反

同一个方法里：

```csharp
new Vector2(JournalTableRightMargin, -JournalTopMargin),
```

锚点与 pivot 都是 `(1, 1)`（右上角）时，X 为正是**往右推出屏幕**。
改成 `-JournalTableRightMargin`。

Y 用负值是对的（往下），别动。

## 验收标准

Henry 会在已经有一整套「建坏了」的 UI 的场景里**重跑两个菜单**，然后点：

1. 编译通过，`git diff` 只有 `UISetupBuilder.cs` 一个文件
2. 重跑 `Residuum/搭建 HUD 与结算界面`，理智条恢复到正常尺寸
   （屏幕左下角一条细长条，不再横跨半个屏幕），准星恢复成一个小方块
3. 选中任意一个 UI 子物体，Inspector 里 `Scale` 是 `1, 1, 1`
4. 重跑 `Residuum/搭建判定笔记本`，按 Tab 打开：
   - 左上角出现三行证据（中文是方框，但看得见方框和「排除」按钮）
   - 右上角出现 4 列 4 行的推理表，**整张表都在屏幕内**，右边不被截断
   - 底部中央出现三个判定按钮
5. 点证据行的「排除」按钮，对应的鬼整行变暗
6. 再跑第三次、第四次同一个菜单，UI 尺寸和位置保持不变，不会越跑越小或越大
7. 按 Ctrl+Z 一次能整体撤销
8. 把 Game 视图分辨率在 `Full HD (1920x1080)` 和 `Free Aspect` 之间来回切，
   重跑菜单后 UI 尺寸都正确（这一条专门验缩放补偿有没有真的被清掉）
