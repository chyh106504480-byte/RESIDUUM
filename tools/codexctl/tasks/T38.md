## 目标

两件事：

1. **EMF 读数器拿在手上就持续发出滴滴声**，读数越高滴得越快
2. **HUD 上显示当前读数**，收起读数器时整个显示隐藏

## 契约已就位

`GameEvents.OnEMFReadingChanged(int)` 已经存在。本任务给它补一个语义
（契约注释已由总控写好，**不要再改 GameEvents.cs**）：

| 值 | 含义 |
|---|---|
| `-1` | **读数器没拿在手上**，HUD 应隐藏整个读数显示 |
| `0` | 拿着，但附近什么都没测到 |
| `1`–`5` | 读数 |

「仪器没拿出来」和「仪器显示 0」是两回事——后者意味着玩家确实在测
但附近什么都没有，这个区别对玩家判断很重要。

## 要改两个文件

### 一、`Assets/_Project/Scripts/Evidence/EMFReader.cs`

**滴滴声：**

```csharp
[Header("音效")]
[Tooltip("滴滴声的音源。建议挂在读数器模型上，Spatial Blend 设 0（2D，拿在手上）")]
[SerializeField] private AudioSource _beepSource;

[Tooltip("单次滴声")]
[SerializeField] private AudioClip _beepClip;

[Range(0f, 1f)]
[SerializeField] private float _beepVolume = 0.7f;

[Tooltip("读数为 0 时两次滴声的间隔秒数")]
[Min(0.05f)]
[SerializeField] private float _beepIntervalAtZero = 1.5f;

[Tooltip("读数为 5 时两次滴声的间隔秒数")]
[Min(0.02f)]
[SerializeField] private float _beepIntervalAtMax = 0.12f;
```

- **拿在手上（`_isEquipped`）就一直滴**，包括读数为 0 的时候——
  「打开就有探测声」是玩家要的反馈，说明仪器在工作
- 间隔按当前读数在 `_beepIntervalAtZero` 与 `_beepIntervalAtMax` 之间
  **线性插值**，读数变化时立刻生效，不要等当前这一拍走完
- 收起（`OnUnequip`）立刻停
- 用 `PlayOneShot(_beepClip, _beepVolume)`，不要用 `Play()`
- `_beepSource` 或 `_beepClip` 为 null 时静默跳过，不报错不打警告

**收起时广播 -1：**

`OnUnequip` 里现有的 `StopReading()` 之后，广播
`GameEvents.RaiseEMFReadingChanged(-1)`。

`OnEquip` 时广播一次当前读数（通常是 0），让 HUD 立刻把显示亮出来。

**注意**：文件里现有的 `SetReading(int level)` 有个
`if (Reading == level) return;` 的去重判断。广播 -1 不要走它，
否则收起再拿出来时如果读数没变就不会重新广播。

`EMFReader` 的其它任何一行都不许改，尤其不要动检测半径、
读数计算、`GhostHasEMF5` 那道闸。

### 二、`Assets/_Project/Scripts/UI/HUDController.cs`

```csharp
[Header("EMF 读数")]
[Tooltip("显示 EMF 读数的文本。收起读数器时隐藏")]
[SerializeField] private TextMeshProUGUI _emfLabel;

[Tooltip("读数文本模板，{0} 会被替换成 0–5 的数字")]
[SerializeField] private string _emfFormat = "EMF  {0}";

[Tooltip("读数 0–2 时的颜色")]
[SerializeField] private Color _emfLowColor = new Color(0.6f, 0.6f, 0.6f, 1f);

[Tooltip("读数 3–4 时的颜色")]
[SerializeField] private Color _emfMidColor = new Color(1f, 0.75f, 0.2f, 1f);

[Tooltip("读数 5 时的颜色")]
[SerializeField] private Color _emfHighColor = new Color(1f, 0.25f, 0.2f, 1f);
```

- 订阅 `GameEvents.OnEMFReadingChanged`。文件里已有的
  `OnEnable` / `OnDisable` 订阅区照着加，两边都要
- 收到 `-1` → `_emfLabel.gameObject.SetActive(false)`
- 收到 `0`–`5` → 激活并显示，按上表换颜色
- `OnRoundStart` 时重置为隐藏；`OnRoundEnd` 时跟随现有的 `HideAll()` 隐藏
- `_emfLabel` 为 null 时整段跳过，不报错——
  这是新加的字段，旧场景里没连也要能跑

`HUDController` 的其它任何一行都不许改。

## 验收标准

1. 编译通过，`git diff` 只有 `EMFReader.cs` 与 `HUDController.cs`
2. 给 EMF 模型加一个 `AudioSource`（`Spatial Blend` = 0）并填滴声，
   拿出读数器：**立刻开始慢速滴滴**，HUD 出现「EMF  0」
3. 走近鬼，读数升高，**滴声明显变快**，HUD 数字跟着变，
   3–4 变琥珀色、5 变红色
4. 按 T 切到手电（收起读数器）：**滴声立刻停**，HUD 的 EMF 显示消失
5. 再切回读数器，滴声和显示都立刻恢复
6. 不填音源或不填 clip 时，读数器照常工作，控制台无任何警告
7. 不连 `_emfLabel` 时 HUD 其余部分照常工作，控制台无报错
8. 按 F10 结束回合，EMF 显示隐藏
