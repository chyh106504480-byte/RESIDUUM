## 背景

`T01 PlayerController` 已经过审，架构合规，只有一处必修：**没有任何 `Cursor.lockState` /
`Cursor.visible` 处理**。进入播放模式后鼠标视角会转到窗口边缘卡住，无法正常测试。

## 目标

在玩家控制器所在的脚本里补上光标锁定，不要新建脚本，不要动其它逻辑。

## 要求

1. 进入游戏（`OnEnable` 或 `Start`）时：`Cursor.lockState = CursorLockMode.Locked`，
   `Cursor.visible = false`。
2. 退出（`OnDisable` / `OnDestroy`）时还原为 `CursorLockMode.None` + `visible = true`，
   否则退出播放模式后编辑器里鼠标会消失。
3. 加一个 `[SerializeField] private bool _lockCursorOnStart = true;`（带中文 Tooltip），
   方便调试时关掉。
4. **不要**在 `Update` 里每帧写 `Cursor.lockState`。
5. **不要**加 Esc 解锁之类的额外功能 —— 那是 T15 暂停菜单的事，现在加会和后面打架。

## 验收标准

- 进播放模式后鼠标被锁在屏幕中央，视角可以 360° 转动不卡边缘。
- 退出播放模式后编辑器鼠标正常。
- `git diff` 只动了玩家控制器一个文件，改动行数 < 25 行。
