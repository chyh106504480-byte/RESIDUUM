## 目标

回合结束时弹出结算面板，告诉玩家：拿了什么等级、真凶是谁、你判的是谁、
用了多久、找到几项证据。再给一个「再来一局」按钮。

**这是推理玩法唯一的兑现时刻。**玩家花整局推断出「是怨灵」，必须在这里
看到答案对不对。

## 契约已就位

`Residuum.Core` 里已经有：

```csharp
public readonly struct RoundSummary
{
    public readonly RoundResult Result;
    public readonly string ActualGhostName;    // 真凶
    public readonly string GuessedGhostName;   // 玩家判定，未提交为 null
    public readonly int FoundEvidenceCount;    // 0–2
    public readonly float ElapsedSeconds;
    public bool HasGuess { get; }
}

public static event Action<RoundSummary> GameEvents.OnRoundSummary;
public static void GameEvents.RaiseRoundSummary(RoundSummary s);
```

**不要自己往 GameEvents.cs 或 RoundResult.cs 里加任何东西。**

## 要做的文件（两个）

### 一、`Assets/_Project/Scripts/Core/GameManager.cs` —— 只加一段

在 `GameEvents.RaiseRoundEnd(result);` 那一行**之后**插入 RaiseRoundSummary，
用同一段代码里已经算好的 `result`、`elapsedSeconds`、`FoundCount`，
以及本局的鬼种定义与 `_submittedGuess`：

**顺序必须是「之后」，别写反。**判定笔记本在 `OnRoundEnd` 里会关闭自己
并重新启用 `PlayerController`（连带把光标锁回去）。结算面板要禁用
`PlayerController` 才能让玩家点到按钮，必须排在笔记本后面执行。
写成「之前」的话，玩家点不到「再来一局」，而且这个 bug 看起来
像是按钮坏了，极难查。

```csharp
GameEvents.RaiseRoundSummary(new RoundSummary(
    result,
    <本局鬼种>.ghostName,
    _submittedGuess != null ? _submittedGuess.ghostName : null,
    FoundCount,
    elapsedSeconds));
```

`<本局鬼种>` 用 GameManager 里已有的字段，不要新加字段。
若本局鬼种为 null（异常路径），传空字符串而不是让它抛异常。

**除这一段外，GameManager 的其它任何一行都不许改。**

### 二、`Assets/_Project/Scripts/UI/ResultScreenUI.cs`，命名空间 `Residuum.UI`

uGUI + TextMeshPro。所有界面引用 `[SerializeField]` 注入，
**不要在代码里创建任何 UI 对象**。

```csharp
[SerializeField] private GameObject _panelRoot;        // 面板根节点，开局隐藏
[SerializeField] private TextMeshProUGUI _gradeLabel;  // 大写字母 S/A/C/F
[SerializeField] private TextMeshProUGUI _titleLabel;  // 一句话结论
[SerializeField] private TextMeshProUGUI _detailLabel; // 多行明细
[SerializeField] private UnityEngine.UI.Button _restartButton;
```

**注意：不要用禁用自身 GameObject 的方式隐藏面板。**本组件必须始终启用
才能收到 `OnRoundSummary`；隐藏的是 `_panelRoot`，不是组件所在的物体。
`_panelRoot` 不允许是本组件自己所在的 GameObject，`Awake` 里检出这种
配置要报错。

### 显示内容

等级字母与标题按 `RoundResult` 映射，四组文案与颜色都做成 `[SerializeField]`：

| Result | 字母 | 标题默认 | 颜色默认 |
|---|---|---|---|
| Perfect | `S` | `完美收工` | `(1, 0.85, 0.3)` |
| Success | `A` | `判定正确` | `(0.4, 0.85, 0.45)` |
| Survived | `C` | `活着回来了，但判错了` | `(0.75, 0.75, 0.75)` |
| Died | `F` | `你没能离开那栋房子` | `(0.7, 0.15, 0.15)` |

明细文本（`_detailLabel`）三到四行，格式做成 `[SerializeField] string` 模板，
用 `string.Format` 填：

```
真凶：{0}
你的判定：{1}
证据：{2} / 2
用时：{3}
```

`GuessedGhostName` 为空时第二行显示 `[SerializeField] string _noGuessText`，
默认 `未提交判定`。用时格式化成 `分:秒`（例如 `4:07`）。

## 光标与输入

面板弹出时要让玩家能点按钮。**不要自己写 `Cursor.lockState` / `Cursor.visible`**。
和判定笔记本用同一个办法——开关场景里的 PlayerController 组件：

```csharp
[Tooltip("拖入玩家身上的 PlayerController 组件。结算面板弹出时会禁用它，" +
         "从而同时停掉移动、视角与光标锁定")]
[SerializeField] private MonoBehaviour _playerControllerBehaviour;
```

字段类型必须是 `MonoBehaviour`，不要引用 Player 模块。为 null 时跳过，不报错。

## 再来一局

`_restartButton` 点击后：

1. 隐藏面板
2. 恢复 `_playerControllerBehaviour.enabled = true`
3. 触发 `public UnityEngine.Events.UnityEvent onRestartRequested`

**不要在代码里直接引用 GameManager**，`onRestartRequested` 由 Henry 在
Inspector 里连到 `GameManager.StartRound`。

另外订阅 `GameEvents.OnRoundStart`，回合开始时强制隐藏面板并恢复
PlayerController——这样即使玩家是从别处重开的，面板也不会留在屏幕上。

## 明确不要做的

- 不要写任何创建 UI 层级的代码
- 不要碰 `Time.timeScale`
- 不要订阅 `OnRoundEnd`（明细已经在 `OnRoundSummary` 里，订两个会重复弹）
- 不要改 `HUDController`、`JournalUI`、`PlayerController`
- 不要在 `Residuum.UI` 里 using `Residuum.Ghost` 或 `Residuum.Player`
- 不要做排行榜、存档、动画过场
- GameManager 里除了那一段 RaiseRoundSummary 之外一行都不许动

不要自己加。写在最终回复里说明签名与理由。本任务预期不需要。

## 验收标准

1. 编译通过；`git diff` 只有 `GameManager.cs`（一段）与新增的
   `ResultScreenUI.cs` 两处
2. 开局时结算面板不可见
3. 按 F11 收齐证据 → 在笔记本里判定正确的鬼 → 走到出口撤离，
   面板弹出显示 `S`，明细里真凶与判定同名、证据 `2 / 2`、用时非零
4. 不提交判定直接撤离，第二行显示「未提交判定」，等级为 `C`
5. 判定错误后撤离，等级 `C`，明细里真凶与判定不同名
6. 被猎杀致死，等级 `F`，标题为死亡文案
7. 面板弹出时鼠标光标可见、可以点到「再来一局」，玩家不能移动
8. 点「再来一局」后面板消失、玩家恢复移动，新一局正常开始
9. 把 `_panelRoot` 拖成组件自己所在的物体，进 Play 时控制台报错说明这一点
