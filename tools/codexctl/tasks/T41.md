## 目标

一个编辑器菜单命令，把紫外线指纹这条证据链**从零到能用**全部铺好：
建材质、给每扇门加指纹 Quad、挂组件、连好鬼的生成请求。

Henry 只需要跑一次菜单。

## 只做一个文件

`Assets/_Project/Scripts/Evidence/Editor/FingerprintBuilder.cs`，
命名空间 `Residuum.Evidence.Editor`

菜单路径：`Residuum/铺设指纹点位`

## 照抄现有编辑器工具的骨架

参照 `Assets/_Project/Scripts/UI/Editor/UISetupBuilder.cs`：

- 全程 `Undo.RegisterCreatedObjectUndo` / `Undo.AddComponent` /
  `Undo.SetTransformParent`，用 `Undo.SetCurrentGroupName` +
  `CollapseUndoOperations` 收成一步，失败 `RevertAllDownToGroup`
- **挂父子关系后必须重置 `localScale` / `localRotation` / `localPosition`**
  —— `Undo.SetTransformParent` 保持世界变换，不重置会继承补偿缩放，
  这个坑 UISetupBuilder 踩过一次（见 T22）
- 幂等：已经建过的复用，不重复建
- `EditorSceneManager.MarkSceneDirty`，**不要自动保存场景**
- 结束打一条日志说明建了几个

## 一、材质

目标路径：`Assets/_Project/Art/Materials/Fingerprint.mat`

不存在就建，存在就复用（**不要覆盖 Henry 调过的参数**）：

- Shader：`Universal Render Pipeline/Unlit`
- `Surface Type` = Transparent，**`Blending Mode` = Additive**
  （用 `material.SetFloat("_Surface", 1)`、`SetFloat("_Blend", 1)`，
  并调 `material.EnableKeyword` / `SetOverrideTag` /
  `renderQueue = (int)RenderQueue.Transparent` 把状态设全，
  只设 Surface Type 不会真的生效）
- `_BaseMap`：在 `Assets/_Project/Art/Textures/` 下用
  `AssetDatabase.FindAssets("t:Texture2D")` 找**文件名里含
  `fingerprint`（不区分大小写）** 的第一张贴图并赋上。
  找不到就 `Debug.LogWarning` 说明没找到、材质仍然建出来，
  **不要中止**

**为什么是 Additive**：手印素材是黑底白纹。叠加混合下黑色加上去等于
没加，白纹发亮——正好是紫外线下手印发光的效果，省掉抠图。

## 二、给每扇门铺指纹

场景里找所有带 `Residuum.World.Door` 组件的物体
（用 `FindObjectsByType<Door>(FindObjectsInactive.Include)`——
**不要用 `FindObjectsOfType`，Unity 6 已弃用**）。

每扇门：

1. 在门物体下找名为 `Fingerprint` 的直接子物体，没有就建一个 `Quad`
   （`GameObject.CreatePrimitive(PrimitiveType.Quad)`）
2. **删掉 Quad 自带的 `MeshCollider`** —— 指纹只是贴图，
   有碰撞体会挡住玩家开门
3. `Scale` 设 `0.18, 0.18, 1`
4. 位置：取门的 `Renderer.bounds`，把 Quad 放在**门板正面、
   靠近门把手一侧、离地约 1 米**处，沿门板法线往外偏 `0.012` 米
   - 门板法线取门物体的 `transform.forward` 或 `right`，
     哪个是"厚度方向"用 `bounds.size` 最小的那个轴判断
   - 偏移方向要朝**远离门板中心**的一侧
5. `Rotation` 让 Quad 正面朝外，和偏移方向一致
6. 材质设为第一步那个
7. `Add Component` → `Residuum.Evidence.Fingerprint`

**位置精确度不重要**，只要贴在门板上、朝外、不穿模就行。
Henry 之后可以手动微调。

## 三、建转发器并连线

1. 场景里找名为 `FingerprintSpawner` 的物体，没有就建一个空物体
   并挂 `Residuum.Evidence.FingerprintSpawner`
2. 找场景里的 `Residuum.Ghost.GhostAI`
3. 用 `UnityEditor.Events.UnityEventTools.AddPersistentListener`
   把 `ghostAI.onFingerprintRequest` 连到
   `FingerprintSpawner.Spawn`

**必须连成动态参数（dynamic）那一档**，不是静态参数。
`onFingerprintRequest` 是 `UnityEvent<Transform>`，要用
`AddPersistentListener<Transform>(evt, UnityAction<Transform>)`
这个泛型重载，鬼交互的目标才能传过去。连成静态的话指纹永远
在错误的位置激活。

连之前先用 `RemovePersistentListener` 清掉同名旧监听，
保证重复跑菜单不会连出多条。

场景里找不到 `GhostAI` 就 `Debug.LogWarning` 点名，**不要中止**。

## 文件二：丢弃的道具要能自由落体

`Assets/_Project/Scripts/Items/ItemSlotSystem.cs`

现在丢弃只是把世界道具对象挪到玩家前方再显示，**没有物理**，
道具会僵在半空。

改成：道具身上如果有 `Rigidbody`，丢弃时让它自然掉下去。

```csharp
[Tooltip("丢弃时给道具的初速度倍率。0 表示原地松手，正数表示往前抛")]
[Min(0f)]
[SerializeField] private float _dropForwardSpeed = 2f;
```

规则：

- **拾取时**（隐藏世界对象前）：若该对象有 `Rigidbody`，
  把 `isKinematic` 设为 `true`、`linearVelocity` 与
  `angularVelocity` 清零。不这么做的话它在被隐藏期间仍然会被物理
  积累速度，重新出现时会乱飞
- **丢弃时**（挪好位置、`SetActive(true)` 之后）：若有 `Rigidbody`，
  `isKinematic` 设为 `false`，并给一个初速度
  `transform.forward * _dropForwardSpeed`
- **回合开始归位时**：同样先 `isKinematic = true` 再摆回初始位置，
  清零速度，**保持 `isKinematic = true`** ——
  道具摆在桌上/架子上不该自己滚下来

**注意 Unity 6 里 `Rigidbody.velocity` 已弃用**，
要用 `linearVelocity`。用错会报 CS0619。

没有 `Rigidbody` 的道具行为完全不变（照旧瞬移到位置），
**不要自动 `AddComponent<Rigidbody>`** —— 加不加由 Henry 在
Inspector 决定。

## 验收标准

1. 编译通过，`git diff` 只有新增的 `FingerprintBuilder.cs`（及其 meta）
   与 `ItemSlotSystem.cs`
2. 跑 `Residuum/铺设指纹点位`，`Assets/_Project/Art/Materials/Fingerprint.mat`
   出现，Shader 是 `Universal Render Pipeline/Unlit`，
   `Surface Type` 是 Transparent、`Blending Mode` 是 Additive
3. 场景里每扇门下面都多了一个 `Fingerprint` 子物体，
   贴在门板表面、不穿模、**没有碰撞体**
4. 每个都挂着 `Fingerprint` 组件，`Scale` 是 `0.18, 0.18, 1`
5. Hierarchy 里出现 `FingerprintSpawner` 物体
6. 选中 `Ghost`，`Ghost AI` 的 `On Fingerprint Request` 里有
   **恰好一条**监听，指向 `FingerprintSpawner.Spawn`，
   且是 **Dynamic Transform** 那一档
7. 再跑两次菜单，门下不会多出第二个 Quad，监听条数仍然是 1
8. Ctrl+Z 一次撤销干净
9. 进 Play：指纹平时**看不见**；鬼交互过某扇门之后，
   拿紫外线灯照那扇门能看到发光的手印，并采集到 UVFingerprint 证据
10. 玩家能正常开关每一扇门，指纹 Quad 不挡路
11. 给墙上某件道具加一个 `Rigidbody`（`Mass` 1、
    `Collision Detection` 选 Continuous），进 Play：它**不会**从
    架子上掉下来
12. 捡起它、按 G 丢弃：道具往前飞一小段并**自然落到地上**，
    不再僵在半空
13. 走过去能再捡起来
14. 按 F10 结束回合再开新一局：道具回到架子上原位，**不会掉下来**
15. 没加 `Rigidbody` 的道具丢弃行为和改动前完全一致
