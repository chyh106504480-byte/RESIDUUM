## 背景

地图的门转换成可交互门之后，关着的门会因为 `NavMeshObstacle.carving = true`
挖断导航网格。而 `GhostAI` 不会开门，于是**鬼被永久困在鬼房里**——
这是 T09 明确划在范围外、留给后续处理的已知限制。

Henry 决定实现它：**鬼撞到关着的门时把它推开。**

## 不需要新契约

`Door` 实现了 `Residuum.Core.IInteractable`，而 `IInteractable` 在 Core，
所以鬼调用它的 `Interact(GameObject)` **不违反跨模块铁律**，
也不需要引用 `Residuum.World`。你已经在 Interact 状态用 `OverlapSphere` +
`_interactableMask` 找 `IInteractable` 了，复用同一套。

## 要改的文件

只改 `Assets/_Project/Scripts/Ghost/GhostAI.cs`。

### 判定「被门挡住」

在 Roam 与 Hunt 状态下，按 `[SerializeField]` 可调间隔（默认 `0.5` 秒）检查一次：

**触发条件（同时满足）：**

- `_agent.hasPath` 为 true 且 `_agent.velocity.sqrMagnitude` 低于可调阈值
  （默认速度 `0.1` m/s 对应的平方值）——**说明有路却走不动**
- 这个「走不动」状态**持续超过可调秒数**（默认 `0.6` 秒），
  避免正常的转身、减速被误判
- 或者 `_agent.pathStatus` 为 `NavMeshPathStatus.PathPartial`
  ——**说明目标可达但当前路径被挖断**

### 开门

满足条件时，用 `Physics.OverlapSphere`（半径 `[SerializeField]` 默认 `1.5`，
沿用 `_interactableMask`）在**鬼前方**找 `IInteractable`：

- 用 `GetComponentInParent<IInteractable>()` 取组件
  —— 门板是子物体、`Door` 在铰链父物体上，这点与 `PlayerInteractor` 一致
- 只对**朝向大致在鬼前方**的目标动手（与 `transform.forward` 的点积为正），
  避免鬼把身后已经走过的门又关上
- 调 `目标.Interact(gameObject)`
- **调用后进入可调冷却**（默认 `1.5` 秒）再允许下一次，
  否则鬼会在门口反复开关

### 必须避免的两件事

1. **不要关门。** `Door.Interact` 是切换式——门开着时再调一次会关上。
   所以调用前先检查：如果目标是已经开着的门就跳过。
   **但不许引用 `Door` 类去读 `IsOpen`**（那是 `Residuum.World` 的具体类）。
   改用 `PromptText`：`IInteractable.PromptText` 在门开着时返回含「关」的文案。
   请以**不依赖具体措辞**的方式实现——建议记录自己开过的目标（用
   `HashSet<IInteractable>` 或最近一次开门的引用），冷却期内不再对同一目标动手，
   并在离开该目标一定距离后清除记录。
2. **不要在 Idle / Interact 状态开门。** 只有 Roam 与 Hunt 需要通行。

### 日志

开门时 `Debug.Log` 一条，写明当前状态与目标名——Henry 验收时要能看出
鬼是不是真的在开门，而不是卡住。日志频率受冷却限制，不会刷屏。

## 明确不要做的

- **不要**引用 `Residuum.World` 的任何具体类（`Door` / `RoomVolume` 都不许）
- **不要**改状态机的结构与既有的巡逻、追击、视线、脚印逻辑
- **不要**改 `Door.cs`
- **不要**让鬼关门
- **不要**碰契约文件
- **不要自己启动 Unity**（见 AGENTS.md）
- 只产出这一个文件的改动

## 验收标准

- 鬼在 Roam 状态走向一扇关着的门，**停顿约半秒后门被推开**，鬼继续前进
- Console 输出一条开门日志，含状态名与门的名字
- 鬼**不会**把已经开着的门关上
- 鬼**不会**在门口反复开关（冷却生效）
- 猎杀状态下追击玩家时同样会开门
- Idle 与 Interact 状态不触发开门
- 鬼身后已通过的门不会被回头开关
- 除 UnityEngine / UnityEngine.AI / UnityEngine.Events / System 外
  只 `using Residuum.Core;`
- 所有数值 `[SerializeField]` + 中文 `[Tooltip]`
- 编译零错误
