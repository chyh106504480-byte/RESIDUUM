## 目标

实现第一人称射线交互系统，以及第一个可交互物：**门**。

## 契约（已存在，不许改）

```csharp
// Assets/_Project/Scripts/World/IInteractable.cs
public interface IInteractable { ... }   // 读它，按它现有签名实现
```

跨模块通信走 `Residuum.Core.GameEvents`。你的文件只允许 `using Residuum.Core;`。

## 要做的文件

1. `Assets/_Project/Scripts/World/PlayerInteractor.cs`
   - 挂在玩家相机上，每帧从相机中心发一条射线
   - `[SerializeField]` 可调：射线距离（默认 2.5）、检测层（LayerMask）、
     检测间隔（默认每帧，可改为每 N 帧以省性能）
   - 命中实现了 `IInteractable` 的对象时，通过 `GameEvents` 广播「当前可交互目标变化」
     （目标为空时广播 null，UI 侧负责显示/隐藏提示）
   - Input System 的 `Interact` action 触发时，调用目标的交互方法
   - **不要**在 `Update` 里 `GetComponent`；命中物体后缓存，直到命中目标改变

2. `Assets/_Project/Scripts/World/Door.cs`
   - 实现 `IInteractable`
   - 开关门用**角度插值**，不用动画：`[SerializeField]` 开门角度（默认 90）、
     开关耗时（默认 0.6s）、铰链 Transform
   - 插值必须帧率无关（`1 - Exp(-k * dt)` 或按时长归一化的 t）
   - 开关途中再次交互 → 反向，不要卡住
   - 门开着的时候提示文案是「关门」，关着是「开门」

## 明确不要做的

- 不要做上锁 / 钥匙 —— 不在切片范围
- 不要做门被鬼推开的逻辑 —— 那是 T10
- 不要做交互提示 UI —— 那是 T14，你只负责广播事件

## 需要新事件怎么办

如果 `GameEvents` 里没有你要的事件，**不要自己加**。在最终回复里写清楚：
事件名、参数签名、什么时候触发。由人类统一加进契约文件。

## 验收标准

- 走到门前 2.5 米内，广播出非空目标；走开广播 null
- 按交互键门平滑开合，来回按不卡死
- 两个文件都只 `using Residuum.Core` + UnityEngine + System
- 所有数值 `[SerializeField]` + 中文 Tooltip，零硬编码魔法数
- 编译零错误
