## 目标

实现第一人称射线交互系统，以及第一个可交互物：**门**。

## 契约（已存在，不许改）

先读这两个文件，按它们**现有的**签名实现，不要凭印象猜：

```
Assets/_Project/Scripts/World/IInteractable.cs   // PromptText / CanInteract / Interact(GameObject)
Assets/_Project/Scripts/Core/GameEvents.cs
```

本任务需要的事件**已经加进契约、可以直接用**：

```csharp
// 准星目标变化时广播提示文案；null = 没有目标，UI 侧隐藏提示
GameEvents.RaiseInteractPromptChanged(string prompt);

// 猎杀期间要缩短交互距离，用这两个现成事件
GameEvents.OnHuntStart(float duration) / GameEvents.OnHuntEnd
```

**注意**：不要自己声明 `public event Action<string> OnPromptChanged`。
提示一律走 `GameEvents`，UI（T14）只订阅事件总线，不认识你的类。

## 要做的文件

### 1. `Assets/_Project/Scripts/World/PlayerInteractor.cs`

命名空间 `Residuum.World`（**不是** `Residuum.Player`）。放在 World 是因为它必须使用
`IInteractable`，而铁律只允许跨模块 `using Residuum.Core` 和 `using Residuum.Evidence`。
同模块就不需要 using，这是唯一合规的落点。

- 挂在玩家相机上，从相机中心（`transform.position` + `transform.forward`）发射线
- **检测节流**：不要每帧射线。`[SerializeField]` 检测间隔，默认 `0.1` 秒
- `[SerializeField]` 可调项（全部带中文 `[Tooltip]`）：
  - 交互距离，默认 `2.5`
  - 猎杀期间交互距离，默认 `1.5`
  - 检测间隔秒数，默认 `0.1`
  - 检测层 `LayerMask`
- 命中实现 `IInteractable` 且 `CanInteract == true` 的对象时，
  调用 `GameEvents.RaiseInteractPromptChanged(目标.PromptText)`
- 目标变为空、或 `CanInteract` 变 false 时，调用 `GameEvents.RaiseInteractPromptChanged(null)`
- **只在目标发生变化时广播**，不要每次检测都重复广播同样的文案
- Input System 的 `Interact` action 触发时，调用当前目标的 `Interact(gameObject)`
- 订阅 `OnHuntStart` / `OnHuntEnd` 切换交互距离，`OnEnable` 订阅、`OnDisable` 退订，严格配对
- **不要**在检测循环里 `GetComponent`：命中物体后把 `IInteractable` 缓存住，
  直到命中的 `Collider` 变化才重新取

### 2. `Assets/_Project/Scripts/World/Door.cs`

命名空间 `Residuum.World`，实现 `IInteractable`。

- 开关门用**角度插值**，不用 Animation/Animator
- `[SerializeField]` 可调项（全部带中文 `[Tooltip]`）：
  - 开门角度，默认 `90`
  - 开关耗时秒数，默认 `0.6`
  - 铰链 `Transform`（为空时用自身，并 `Debug.LogWarning` 提示）
- 插值必须**帧率无关**（按时长归一化的 t，或 `1 - Exp(-k * dt)`）
- 开关途中再次交互 → **反向**，不要卡住、不要排队、不要等当前动画放完
- `PromptText`：开着时返回关门提示，关着时返回开门提示（照 `IInteractable` 注释里
  `"[E] 开门"` 的格式写）
- 提供 `public bool IsOpen { get; private set; }`
- **NavMeshObstacle**：门上取 `NavMeshObstacle`（`Unity.AI.Navigation` 不需要，
  `NavMeshObstacle` 在 `UnityEngine.AI`）。关闭状态 `carving = true`，
  开启状态 `carving = false`。组件不存在时不要报错，静默跳过即可。
  这条是给 T09 鬼 AI 寻路用的，现在不做等于后面要回来重开这个文件。

## 明确不要做的

- **不要做上锁 / 钥匙** —— 不在切片范围
- **不要做 `ForceOpen` / 鬼推开门的逻辑** —— 那是 T10，届时连带解决「鬼怎么够到门」
  的跨模块问题，现在加会定死一个错的接口
- **不要做交互提示 UI** —— 那是 T14，你只负责广播事件
- **不要做门的音效事件** —— 那是 T17
- **不要碰 `PlayerController.cs`**，也不要碰任何契约文件
- 只产出上面两个文件，不要顺手加 `InteractableBase` 之类的辅助基类

## 需要新事件怎么办

事件名、参数签名、什么时候触发、为什么现有事件表达不了。由人类统一加进契约文件。

## 验收标准

- 走到门前 2.5 米内，`OnInteractPromptChanged` 广播出非空文案；走开广播 null
- 同一个目标持续注视时，不会重复刷广播
- 按交互键门平滑开合；开到一半再按立刻反向，来回按不卡死
- 猎杀开始后交互距离缩到 1.5 米，猎杀结束恢复 2.5 米
- 两个文件除 UnityEngine / System 外，只允许 `using Residuum.Core;`
- 所有数值 `[SerializeField]` + 中文 `[Tooltip]`，零硬编码魔法数
- 编译零错误
