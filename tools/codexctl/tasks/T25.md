## 目标

两件事：

1. 墙上装一个开关，按 E 开关一组灯
2. 让 `PlayerSanity` 能接住外部施加的一次性理智惩罚（停电时要用）

## 契约已就位

```csharp
/// 参数：扣除的理智点数，0–100 标度上的绝对值，正数表示扣减
public static event Action<float> GameEvents.OnSanityPenalty;
public static void GameEvents.RaiseSanityPenalty(float points);
```

**不要自己往 GameEvents.cs 加任何东西。**

## 好消息：理智对黑暗的反应已经有了

`PlayerSanity` 的 `_useLightProbe` 已经在定期检测附近有没有启用的 `Light`，
黑暗中衰减用 `_darkDecayRate`、有灯用 `_litRoomDecayRate`。
**灯一灭理智掉得更快这件事现在就已经生效了，不需要你接线。**

本任务只补「一次性扣一笔」这条路。

## 要改两个文件

### 一、`Assets/_Project/Scripts/Player/PlayerSanity.cs` —— 只加一段

在 `OnEnable` / `OnDisable` 已有的订阅旁边加上
`GameEvents.OnSanityPenalty`，处理函数把传入点数从当前理智里扣掉。

**复用文件里已有的那条改理智的私有方法**（约 205 行，
`Mathf.Clamp(previous + delta, MinimumSanity, MaximumSanity)` 那段），
它已经负责广播 `OnSanityChanged`、判定临界与阈值跨越。
**不要另写一套扣减逻辑，也不要直接写 `Current`。**

传入负数或 0 时忽略并 `Debug.LogWarning`——理智惩罚只能是扣减，
恢复走已有的安全区逻辑。

`PlayerSanity` 的其它任何一行都不许改，尤其不要动衰减速率、
阈值、光照探测那几段。

### 二、`Assets/_Project/Scripts/World/LightSwitch.cs`（新建），命名空间 `Residuum.World`

实现 `Residuum.Core.IInteractable`。

```csharp
[Tooltip("这个开关控制的灯。可以是一盏也可以是一屋子")]
[SerializeField] private Light[] _lights;

[Tooltip("开局时这组灯是否亮着")]
[SerializeField] private bool _startsOn = true;

[Tooltip("灯亮着时的提示")]
[SerializeField] private string _turnOffPromptText = "[E] 关灯";

[Tooltip("灯灭着时的提示")]
[SerializeField] private string _turnOnPromptText = "[E] 开灯";
```

- `PromptText` —— 按当前开关状态返回两句之一
- `CanInteract` —— `_lights` 非空且至少有一盏不为 null 时为 true
- `Interact(GameObject)` —— 翻转状态，把 `_lights` 里每盏灯的
  `enabled` 设成新状态
- `Awake` —— `_lights` 为空或全是 null 时 `Debug.LogError` 点名这个物体；
  数组里个别为 null 的项跳过即可，不要报错刷屏
- `Start` 里按 `_startsOn` 应用一次初始状态

订阅 `GameEvents.OnRoundStart`，回合开始时把灯恢复成 `_startsOn` 的状态。
`OnEnable` 订阅、`OnDisable` 取消订阅，两边都要写。

**不要碰 `Light.intensity` 或颜色**，只开关 `enabled`——
`PlayerSanity` 的光照探测判据就是「附近有没有已启用的 Light」，
改 intensity 骗不过它，反而会让黑暗中理智不掉。

## 验收标准

Henry 会拿场景里现成的灯来试：

1. 编译通过，`git diff` 只有 `PlayerSanity.cs` 与新增的 `LightSwitch.cs`
2. 场景里放个方块当开关、挂 `LightSwitch`、把附近几盏 `Light` 拖进
   `_lights`、给方块加碰撞体
3. 瞄准它出现「[E] 关灯」，按 E 灯全灭、提示变成「[E] 开灯」
4. 再按 E 灯全亮
5. 关灯后待在暗处，HUD 的理智条下降速度明显比开灯时快
   （这条验的是既有的 `_useLightProbe` 仍然工作，没被本任务破坏）
6. `_startsOn` 取消勾选，进 Play 时那组灯是灭的
7. 灯关着的时候按 F10 结束回合再开新一局，灯恢复成 `_startsOn` 的状态
8. 在 `GameManager` 上临时加一句 `GameEvents.RaiseSanityPenalty(10f)`
   的调试调用（或用 Inspector 的 ContextMenu 触发），理智立刻掉 10 点，
   HUD 理智条跟着变短
9. `RaiseSanityPenalty(-5f)` 时理智不变，控制台出现一条警告
