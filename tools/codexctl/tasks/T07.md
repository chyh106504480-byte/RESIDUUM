## 目标

第三件也是最后一件证据设备。**做完它，3×3 推理表就完整了**——三种证据齐备，
每种鬼恰好持有两项，集齐两项唯一确定鬼种。这是整个设计的骨架。

两者都为默认值（半径 ≤ 0）时视为「鬼房未设定」，此时判定一律不通过并
`Debug.LogWarning` 一次，不要每次判定都刷日志。

## 要做的文件

只产出 `Assets/_Project/Scripts/Evidence/GhostWritingBook.cs`，
命名空间 `Residuum.Evidence`，**同时实现 `IHoldable` 与 `IInteractable`**。

### 两种状态

`public bool IsPlaced { get; private set; }` —— 手持中 / 已放置在世界里。

**手持时**（`IHoldable`）：
- `OnPrimaryUse()` 把书放到玩家前方地面：从玩家相机或自身位置向前下方发射线
  找地面，按命中点与法线贴地摆放。射线距离与向下偏移做成 `[SerializeField]`
  （默认距离 `1.5`、向下 `2`）
- 找不到地面时不放置，`Debug.LogWarning` 说明，**不要把书扔进虚空**
- 放置后 `IsPlaced = true`，并触发 `public UnityEvent onPlaced`，
  供道具槽在 Inspector 里连线做「从槽位移除」——**不要直接引用 `ItemSlotSystem`**

**已放置时**（`IInteractable`）：
- `CanInteract` 仅在 `IsPlaced` 为 true 时返回 true
- `PromptText` 返回捡回提示（照 `IInteractable` 注释里 `"[E] 开门"` 的格式写）
- `Interact(GameObject)` 把书捡回：`IsPlaced = false`，停止判定协程，
  触发 `public UnityEvent onPickedUp` 供道具槽连线

### 判定协程

放置后开始，每隔 `[SerializeField]` 间隔（默认 `30` 秒）判定一次。
**三个条件全部满足才成功**：

1. `GameEvents.GhostHasGhostWriting` 为 true
2. 书本位置到 `GameEvents.GhostRoomCenter` 的距离 ≤ `GameEvents.GhostRoomRadius`
3. `Random.value` 通过成功率检定，成功率 `[SerializeField]` 默认 `0.3`

**第 1 条是 3×3 推理表的守门条件**：鬼种不持有这项证据时**永远不能出书写**，
无论玩家等多久、书放得多准。不许有任何绕过路径。

成功时：
- 切换到「已书写」外观：`[SerializeField]` 两个 `GameObject`（未书写 / 已书写）
  或一个 `Renderer` + 两个 `Material`，**两种方式都支持，由 Inspector 选**，
  两者都没配时只 `Debug.LogWarning` 一次
- 触发 `public UnityEvent onWritingAppeared`，供粒子与音效在 Inspector 里连线
- 调 `GameEvents.RaiseEvidenceFound(EvidenceType.GhostWriting)`
- **停止判定**，本回合不再触发
- `public bool HasWriting { get; private set; }` 置 true

## 验收标准

- 装备鬼影书，左键放到脚下地面，书贴地摆放不悬空、不入地
- 放置后按 E 能捡回，捡回后不再判定
- 把 `GameEvents.GhostRoomCenter` 设到书本位置附近、`GhostRoomRadius` 设 `5`、
  `GhostHasGhostWriting` 设 true，等待 30 秒后有 30% 概率出现书写，
  外观切换并输出证据发现日志
- **`GhostHasGhostWriting` 为 false 时，无论等多久、书放得多准，永远不出书写**
- 鬼房未设定（半径 ≤ 0）时判定不通过，且只警告一次不刷屏
- 出现书写后不再重复上报
- 除 UnityEngine / UnityEngine.Events / System 外只 `using Residuum.Core;`
- 所有数值 `[SerializeField]` + 中文 `[Tooltip]`，零硬编码魔法数
- 编译零错误
