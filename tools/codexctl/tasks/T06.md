## 目标

第二件证据设备：紫外线灯，以及它照出来的指纹。设计意图是**装备 UV 期间房间
全黑**（手电被强制熄灭），玩家几乎失明，必须停在原地承担风险——这是这件道具
的恐惧来源，不要削弱它。

## 要做的文件

### 1. `Assets/_Project/Scripts/Evidence/Fingerprint.cs`

命名空间 `Residuum.Evidence`。挂在门把手、开关、窗台等可留指纹的物体上。

- **平时完全不可见**：默认状态下渲染器关闭（或材质 alpha 为 0），
  只有被 UV 照到才显现
- `public void Reveal()`：让指纹可见
- `public bool IsActive { get; private set; }`：是否处于「存在」状态
- 生命周期：`Activate()` 之后存在 `[SerializeField]` 可调时长（默认 `60` 秒），
  然后自动失效并隐藏
- `public static Fingerprint SpawnAt(Transform target)`：在目标位置生成一个指纹。
  用 `[SerializeField]` 的预制体引用做不到静态方法里，所以这里改为：
  在目标上 `GetComponentInChildren<Fingerprint>(true)` 找到已存在的指纹组件
  并 `Activate()`，找不到就 `Debug.LogWarning` 返回 null。
  **不要在运行时 Instantiate 预制体**——指纹点位由关卡预先布置，
  这样美术替换灰盒时能保证指纹跟着道具走
- `[SerializeField]` 可调项全部带中文 `[Tooltip]`
- 协程在 `OnDisable` 中停止

### 2. `Assets/_Project/Scripts/Evidence/UVLight.cs`

命名空间 `Residuum.Evidence`，实现 `IHoldable`。

- `[SerializeField] private Light _spotLight`（子物体上的紫色 URP Spot Light），
  为空时 `Debug.LogError`
- `[SerializeField]` 可调项（全部带中文 `[Tooltip]`）：
  灯光颜色、强度、锥角、检测半径默认 `4`（米）、检测间隔默认 `0.2`（秒）、
  满电秒数默认 `180`、低电量阈值默认 `0.2`
- `OnPrimaryUse()` 切换开关
- 开启时每隔检测间隔用 `Physics.OverlapSphere` + **光锥角度判断**
  找出射程内且在锥内的所有 `Fingerprint`
- 对每个 `IsActive` 为 true 的指纹调用 `Reveal()`
- **首次**照到有效指纹时调用 `GameEvents.RaiseEvidenceFound(EvidenceType.UVFingerprint)`，
  **同一回合只触发一次**（订阅 `OnRoundStart` 重置）
- 电量系统同手电筒但更短（默认 180 秒），耗尽自动关闭
- **互斥**：`OnEquip()` 时触发 `public UnityEvent<bool> onRequestFlashlightLock`
  传 `true`，`OnUnequip()` 时传 `false`。
  **不要直接引用 `Flashlight` 类**——Henry 会在 Inspector 里把这个 UnityEvent
  连到 `Flashlight.ForceOff`
- `OverlapSphere` 用**非分配版本** `Physics.OverlapSphereNonAlloc` 配一个
  预分配缓冲数组，缓冲大小做成 `[SerializeField]`（默认 `32`），
  不要每次检测都分配新数组
- 协程 `WaitForSeconds` 缓存复用；`OnUnequip` / `OnDisable` 停止所有协程

## 明确不要做的

- **不要引用 `Residuum.Items` 的任何具体类**，包括 `Flashlight`。互斥走 UnityEvent
- **不要引用 `Residuum.Ghost`**
- **不要**让鬼来生成指纹的逻辑 —— 那是 T09，它会通过 UnityEvent 调 `SpawnAt`
- **不要做 UV 灯的 UI 或音效**
- **不要**自己实现证据去重与计数 —— 那是 T08
- 只产出上面两个文件

## 验收标准

- 场景里放几个带 `Fingerprint` 的物体，平时完全看不见
- 手动调用 `Fingerprint.SpawnAt(那个物体的 Transform)` 后，指纹进入「存在」状态
  但仍不可见
- 装备 UV 灯并开启，照向该物体时指纹显现，输出证据发现日志
- 再照一次**不重复记录**
- 移开光锥或超出 4 米，不再触发
- 指纹 60 秒后自动失效，之后照不出来
- 装备 UV 时 `onRequestFlashlightLock` 触发 true，卸下时触发 false
- 两个文件除 UnityEngine / System 外只 `using Residuum.Core;`
- 所有数值 `[SerializeField]` + 中文 `[Tooltip]`，零硬编码魔法数
- 编译零错误
