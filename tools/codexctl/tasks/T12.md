## 目标

理智是全游戏张力的来源：它只降不升（除非回基地），越低猎杀概率越高。
玩家每多找一件证据，都是在拿命换——这个张力就是游戏的全部。

## 要做的文件

只产出 `Assets/_Project/Scripts/Player/PlayerSanity.cs`，命名空间 `Residuum.Player`，
挂在玩家身上。

### 数值（全部 `[SerializeField]` + 中文 Tooltip，默认值照 GDD）

| 项 | 默认 |
|---|---|
| 起始理智 | `100` |
| 黑暗中衰减 | `0.12` /秒 |
| 有灯光房间衰减 | `0.06` /秒 |
| 手持开启手电时的速率倍率 | `0.5` |
| 目击鬼事件一次性扣减 | `15` |
| 猎杀期间额外衰减 | `0.5` /秒 |
| 安全区恢复 | `1.0` /秒 |
| 猎杀阈值 | `50` |
| 鬼事件生效距离 | `15` 米 |
| 光源检测间隔 | `0.5` 秒 |
| 光源检测半径 | `8` 米 |

理智上限 `100`、下限 `0`，随时钳制。

### 是否在黑暗中

`[SerializeField] private bool _useLightProbe`，默认 **true**：

- **true（推荐方式）**：每隔检测间隔用 `Physics.OverlapSphere` 找附近半径内
  **启用着的** `Light` 组件，找到任意一个就算「有光」。
  用 `OverlapSphereNonAlloc` + 预分配缓冲，不要每次检测都分配数组
- **false（简单方式）**：完全依赖外部调用 `public void SetInLitRoom(bool)`

两种方式都要实现，由 Inspector 开关选择。

### 手电筒状态

**不要引用 `Residuum.Items.Flashlight`。** 暴露 `public void SetFlashlightOn(bool)`，
由 Inspector 的 UnityEvent 连线驱动。

### 事件处理

- 订阅 `OnGhostEvent`：事件位置在生效距离内**且有视线**（`Physics.Linecast`
  被 `[SerializeField] LayerMask` 遮挡则无视线）时扣 15 点。
  **同一次鬼事件只扣一次**
- 订阅 `OnHuntStart` / `OnHuntEnd` 控制额外衰减的开关
- **安全区**：`[SerializeField] private Collider _safeZone`，玩家在其中时按
  恢复速率回升。用 `_safeZone.bounds.Contains(transform.position)` 判定即可。
  为空时不报错，只是没有安全区

### 广播

- 每次数值变化调 `GameEvents.RaiseSanityChanged(当前值)`。
  **只在变化超过可调阈值（默认 `0.1`）时才发**，不要每帧刷爆事件总线
- 首次跌破猎杀阈值调 `RaiseSanityCritical()`，**整局只发一次**
- 每跌破 25 的整数倍（75 / 50 / 25）调 `RaiseSanityThresholdCrossed(该阈值)`。
  理智回升后再次跌破同一阈值要能再次触发
- `public float Current { get; private set; }`

### 其他

- 订阅 `OnRoundStart` 重置：理智回满、所有标志归零、协程重启
- `OnEnable` 订阅 / `OnDisable` 退订严格配对；协程在 `OnDisable` 停止
- `WaitForSeconds` 缓存复用，不要在循环里 `new`
- **不要每帧 `Camera.main`**

## 明确不要做的

- **不要**碰契约文件

## 验收标准

- 在黑暗中站着，理智按 0.12/秒 稳定下降，HUD 侧能收到 `OnSanityChanged`
- 附近放一盏启用的 Light，衰减降到 0.06/秒
- 调 `SetFlashlightOn(true)` 后上述速率再减半
- 手动 `GameEvents.RaiseGhostEvent(玩家附近的点)` 扣 15 点；
  同一事件不重复扣；距离超过 15 米不扣；中间隔墙不扣
- 手动 `RaiseHuntStart(20f)` 后额外多掉 0.5/秒，`RaiseHuntEnd()` 后恢复
- 站进安全区 Collider，理智以 1.0/秒 回升，上限 100
- 首次跌破 50 时 `RaiseSanityCritical` **只发一次**
- 跌破 75 / 50 / 25 各发一次 `RaiseSanityThresholdCrossed`；
  回升后再跌破同一阈值能再次触发
- `OnRoundStart` 后理智回满、所有标志归零
- 除 UnityEngine / System 外只 `using Residuum.Core;`
- 所有数值 `[SerializeField]` + 中文 `[Tooltip]`，零硬编码魔法数
- 编译零错误
