## 背景

下蹲目前是**按住式**（`Crouch` action 按住才蹲，松开就起）。实际游玩时
需要长时间保持蹲伏躲避鬼，一直按着 `C` 很累。Henry 要求改为**切换式**：
按一下蹲下，再按一下站起。

## 要改的文件

只改 `Assets/_Project/Scripts/Player/PlayerController.cs`。

- `Crouch` action 改为监听**按下事件**（`performed`），每次触发翻转蹲伏状态，
  不再读取按键的持续按压状态
- 保留现有的 `_crouchTransitionTime` 平滑过渡、`_crouchingHeight`、
  `_crouchSpeed`、蹲伏时的头部晃动倍率等全部既有行为，**只改触发方式**
- `public bool IsCrouched { get; private set; }` 的语义不变

### 必须处理的边界：站起来时头顶有障碍

切换式会引入一个按住式没有的问题：玩家在矮空间里按键站起，会把角色卡进天花板。

**站起之前必须检测头顶空间**：从角色当前位置向上做球形或胶囊检测
（用现有的 `_ceilingMask` 字段；`CLAUDE.md` 记录过它默认为 `~0`，
场景有内容后需要排除玩家自身所在层——**如果当前实现已经处理了自身层的排除就沿用，
没有的话在检测时排除玩家自己的碰撞体**）。

- 头顶空间不足 → **保持蹲伏**，不要强行站起
- 可以每帧或按可调间隔重试，一旦离开矮空间就自动站起

新增的可调项照铁律做成 `[SerializeField] private` + 中文 `[Tooltip]`。

### 输入订阅

`performed` 的订阅与退订必须在 `OnEnable` / `OnDisable` 中严格配对，
沿用文件里 `_crouchActionEnabledHere` 那套「只禁用本组件自己启用过的 action」的写法。

## 明确不要做的

- **不要**改移动、冲刺、视角、光标锁定的任何逻辑
- **不要**改 `Crouch` action 在输入资产里的绑定（保持 `C` 键与手柄 buttonEast）
- **不要**碰输入资产文件
- **不要**改蹲伏的速度、高度、过渡时长等既有默认值
- **不要**碰契约文件
- **不要自己启动 Unity**（见 AGENTS.md）
- 只产出这一个文件的改动

## 验收标准

- 按一下 `C` 蹲下并保持，松手不会站起
- 再按一下 `C` 站起
- 蹲伏过程仍是平滑过渡，不是瞬间切换
- 蹲伏时移动速度为 1.4 m/s，头部晃动幅度按既有倍率减小
- **在矮空间（如桌子底下）按 `C` 站起，角色保持蹲伏不会卡进天花板**；
  走出矮空间后自动站起
- 反复快速按 `C` 不会导致状态错乱或卡在中间高度
- 编译零错误
