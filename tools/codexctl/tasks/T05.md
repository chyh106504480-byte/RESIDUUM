## 目标

第一件证据设备：EMF 读数器。鬼与场景物体互动时它会跳读数，读数到 5 级即为
「EMF-5」证据。三种鬼里有两种持有这项证据。

## 契约（已存在，不许改）

```
Assets/_Project/Scripts/Core/IHoldable.cs      // ItemName / OnEquip / OnUnequip / OnPrimaryUse
Assets/_Project/Scripts/Evidence/EvidenceType.cs
Assets/_Project/Scripts/Core/GameEvents.cs
```

**注意 `IHoldable` 在 `Residuum.Core`**，不在 `Residuum.Items`。你的文件
命名空间是 `Residuum.Evidence`，`using Residuum.Core;` 就够了。

可以直接用的现成事件与静态属性：

```csharp
GameEvents.OnGhostInteract(Vector3 位置)   // 鬼与物体互动，订阅它
GameEvents.GhostHasEMF5                    // 本回合鬼种是否持有 EMF5，只读
GameEvents.RaiseEvidenceFound(EvidenceType.EMF5)
GameEvents.RaiseEMFReadingChanged(int level)   // 读数变化，音频（T17）订阅
```

## 要做的文件

只产出 `Assets/_Project/Scripts/Evidence/EMFReader.cs`，命名空间 `Residuum.Evidence`，
实现 `IHoldable`。

- 读数 `1`–`5` 级，`public int Reading { get; private set; }`
- 订阅 `GameEvents.OnGhostInteract`。收到事件后，若**自身位置**到事件位置的距离
  在检测半径内，则在持续时长内显示读数；超出半径不响应
- `[SerializeField]` 可调项（全部带中文 `[Tooltip]`）：
  - 检测半径，默认 `6`（米）
  - 读数持续时长，默认 `8`（秒）
  - 最高级距离阈值，默认 `2`（米以内给最高级）
  - 读数刷新间隔，默认 `0.25`（秒）
- **读数按距离衰减**：距离越近级别越高，最高级距离阈值内为最高级
- **关键规则**：最高级是 `4` 还是 `5`，取决于 `GameEvents.GhostHasEMF5`。
  为 true 时可以到 5，为 false 时**封顶 4**。这是 3×3 推理表的核心，
  不能让没有 EMF5 证据的鬼跳出 5 级
- 读数达到 5 时调用 `GameEvents.RaiseEvidenceFound(EvidenceType.EMF5)`，
  **同一回合只触发一次**（订阅 `GameEvents.OnRoundStart` 重置这个标志）
- 每次读数**变化时**（不是每次刷新）调用 `GameEvents.RaiseEMFReadingChanged(level)`
- **显示方式给两种，由 Inspector 选**：
  - `[SerializeField] private TMPro.TextMeshPro _readingLabel`（可为空）
  - `[SerializeField] private Renderer[] _indicatorLights`（可为空），
    按当前级别点亮前 N 个（用 `MaterialPropertyBlock` 改 emission，
    **不要**每帧 `new Material`，那会泄漏材质实例）
  - 两个都为空时只 `Debug.LogWarning` 一次，不要每帧刷
- `OnUnequip()` 必须停止所有协程并把读数归零；未装备时不响应事件
- 协程里的 `WaitForSeconds` 缓存为字段复用，不要在循环里 `new`
- `OnEnable` 订阅 / `OnDisable` 退订，严格配对

## 明确不要做的

- **不要做蜂鸣音效** —— 那是 T17，你只广播 `RaiseEMFReadingChanged`
- **不要做 HUD 上的读数显示** —— 那是 T14；你只负责手持模型上的显示
- **不要引用 `Residuum.Ghost` 的任何类型**。要判断鬼种是否持有 EMF5，
  只能读 `GameEvents.GhostHasEMF5`
- **不要引用 `Residuum.Items` 的任何具体类**（`IHoldable` 在 Core，不在 Items）
- **不要**自己实现证据去重与计数 —— 那是 T08 证据管理器
- 只产出这一个文件

## 验收标准

- 装备 EMF 后，手动调用 `GameEvents.RaiseGhostInteract(玩家附近的点)`，读数跳动，
  距离越近级别越高，持续 8 秒后归零
- 距离超过 6 米时调用同一事件，读数不动
- `GameEvents.GhostHasEMF5 = false` 时，无论多近读数**封顶 4**，不出证据
- `GhostHasEMF5 = true` 且贴近时读到 5，输出证据发现日志，**再触发一次不重复记录**
- 卸下道具后读数归零、不再响应事件
- 除 UnityEngine / TMPro / System 外只 `using Residuum.Core;`
- 所有数值 `[SerializeField]` + 中文 `[Tooltip]`，零硬编码魔法数
- 编译零错误
