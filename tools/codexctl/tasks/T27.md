## 目标

两件事：

1. **鬼在巡逻期间按概率短暂现身**（默认 20%），伴随广播 `OnGhostEvent`
2. **猎杀期间鬼的模型闪烁**，忽隐忽现

## 现状（先读明白）

`GhostAI` 里这套机制**已经造好了，但从来没人按开关**：

- `TriggerGhostEvent()`（`GhostAI.cs:528`）是 public 的：广播
  `GameEvents.RaiseGhostEvent(transform.position)`，并让鬼显形
  `_ghostEventVisibleDuration` 秒（默认 2 秒）
- **全仓库没有任何地方调用它**（`Assets/_Project/Scripts/` 下只有定义处）
- `RefreshVisibility()`（1499 行）按 `_huntVisible || _ghostEventVisible`
  统一开关 `_renderers`

所以本任务不是造新机制，是**接上开关**并加闪烁。

## 只改一个文件

`Assets/_Project/Scripts/Ghost/GhostAI.cs`

## 一、巡逻现身

加两个字段，放进已有的 `[Header("显形与调试")]` 那一段：

```csharp
[Tooltip("巡逻期间两次现身判定之间的间隔秒数")]
[Min(0f)]
[SerializeField] private float _manifestCheckInterval = 20f;

[Tooltip("每次判定触发现身的概率")]
[Range(0f, 1f)]
[SerializeField] private float _manifestChance = 0.2f;
```

行为：

- 只在 `GhostState.Roam` 与 `GhostState.Idle` 下判定。
  **猎杀（Hunt）与追击状态下不判定**——那时候鬼本来就是可见的
- 每 `_manifestCheckInterval` 秒滚一次，命中就调已有的 `TriggerGhostEvent()`
- 玩家正在躲藏（`_isPlayerHiding`）时**不要现身**，否则玩家在柜子里
  也会被扣理智，而他什么都没看见
- 计时在 `HandleRoundStart` 里重置

**不要另写显形逻辑**，只调 `TriggerGhostEvent()`。

## 二、猎杀期模型闪烁

加三个字段：

```csharp
[Tooltip("猎杀期间模型闪烁的间隔秒数")]
[Min(0f)]
[SerializeField] private float _huntFlickerInterval = 0.15f;

[Tooltip("每次闪烁时模型保持可见的概率")]
[Range(0f, 1f)]
[SerializeField] private float _huntFlickerVisibleChance = 0.7f;

[Tooltip("关掉后猎杀期间模型保持常亮，便于调试")]
[SerializeField] private bool _huntFlickerEnabled = true;
```

行为：

- `_huntVisible` 为真且 `_huntFlickerEnabled` 时，每
  `_huntFlickerInterval` 秒按 `_huntFlickerVisibleChance` 重设
  `_renderers` 的 `enabled`
- 猎杀结束时**必须调一次 `RefreshVisibility()`**把可见性交还给它，
  不能让闪烁的中间状态留下来

**这里最容易写错的地方**：`RefreshVisibility()` 会把所有 renderer
统一设成 `_huntVisible || _ghostEventVisible`。如果闪烁和它同时在跑，
两者会互相覆盖，表现为「闪得不规律」或「根本不闪」。

处理办法：闪烁进行中时让 `RefreshVisibility()` 直接返回（加一个
`_huntFlickerActive` 标志），闪烁结束再让它接管。
**不要改 `SetVisible` 的实现。**

## 明确不要做的

- 不要改 `HuntController`、`GameManager`、`PlayerSanity`、`LightManager`
- 不要往 `GameEvents.cs` 加任何东西——`OnGhostEvent` 已经够用
- 不要碰灯光（灯变红是 T28 的事）
- 不要做音效（那是 T29）
- 不要改鬼的移动、寻路、开门、猎杀触发逻辑
- 不要改 `_ghostEventVisibleDuration` 的默认值
- 不要新建文件

## 验收标准

1. 编译通过，`git diff` 只有 `GhostAI.cs` 一个文件
2. 把 `_manifestCheckInterval` 临时调成 3 秒、`_manifestChance` 调成 1，
   进 Play 后鬼每隔 3 秒在原地现身 2 秒再消失
3. 现身时 HUD 理智条掉一截（既有的 `OnGhostEvent` 反应，验它没被破坏）
4. 躲进衣柜（若场景里有 `HidingSpot`）后鬼不再现身
5. 按 P 强制猎杀，鬼的模型**明显在闪**，不是常亮也不是常灭
6. 猎杀结束后鬼恢复成完全不可见，不会留下半闪的状态
7. `_huntFlickerEnabled` 取消勾选后，猎杀期间鬼常亮（便于调试鬼的走位）
8. 把两个值改回 20 秒 / 0.2，一局下来大概现身一到两次
