## 目标

两条规则改动：

1. **手电筒不再需要拾取**，开局就有，按 T 取出/收起
2. **三件证据道具一次只能带一件**。手上有道具时按 E 拾取**完全不生效**，
   必须先按 G 丢掉、空了手才能拿

不做自动交换。玩家要换工具就得走回去放下再拿——这是设计意图，
让"带哪件工具出门"成为一个真实的取舍。

## 要改两个文件

### 一、`Assets/_Project/Scripts/Items/ItemSlotSystem.cs`

**手电改为自带：**

- 手电在 `Awake` / 回合开始时**就是已持有状态**，不需要拾取
- 删掉 `_flashlightWorldItem` 字段与 `TryPickUpFlashlight()` 方法——
  手电不再有世界对象，也不再需要拾取入口
- 按 T 的既有行为保留：在手电与当前编号槽之间来回切
- **手电不能被 G 丢弃**。当前拿着手电时按 G 无反应

新增一个字段：

```csharp
[Tooltip("回合开始时是否自动把手电拿在手上")]
[SerializeField] private bool _equipFlashlightOnRoundStart = true;
```

**三选一：**

- 新增 `public bool HasAnySlotItem { get; }` —— 三个编号槽里是否已经持有任意一件
- `TryPickUpSlot(int index)` 在 `HasAnySlotItem` 为真时**直接返回 false**，
  什么都不做、不报错、不打日志
- 按 G 丢弃编号槽道具后 `HasAnySlotItem` 变回 false，此时才能拿新的

`_worldItems` 数组保留（长度 3），拾取隐藏、丢弃移到玩家前方、
回合开始归位这些既有行为不变。

### 二、`Assets/_Project/Scripts/Items/WorldItem.cs`

- 删掉 `_isFlashlight` 字段与走手电路径的分支——手电不再是世界道具
- `CanInteract` 保持恒为 true
- **`PromptText` 改成三态**：

```csharp
[Tooltip("手上已有道具时的提示")]
[SerializeField] private string _handsFullPromptText = "先放下手上的道具";
```

| 情况 | 提示 |
|---|---|
| 手上空着 | `string.Format(_promptFormat, _itemName)`，即「[E] 捡起 EMF 读数器」 |
| 手上已有编号槽道具 | `_handsFullPromptText` |
| 找不到 `ItemSlotSystem` | 沿用现有的容错，返回原提示即可 |

判断「手上是否已有」要读 `ItemSlotSystem.HasAnySlotItem`。
`PromptText` 每帧都会被 `PlayerInteractor` 读，
**不要在这个属性里做 `GetComponentInChildren` 这类查找**——
缓存一个引用，或者在 `Awake` 里用
`UnityEngine.Object.FindAnyObjectByType<ItemSlotSystem>()` 取一次。

**`FindAnyObjectByType` 是 Unity 6 里唯一没被弃用的单体查找 API**，
不要用 `FindObjectOfType` 或 `FindFirstObjectByType`，那两个都会报
CS0619。

- `Interact` 里照常调 `TryPickUpSlot(_slotIndex)`，返回 false 就静默返回

## 明确不要做的

- 不要做自动交换、自动放回原位
- 不要改 `Flashlight`、`EMFReader`、`UVLight`、`GhostWritingBook`
- 不要改 `IHoldable` 契约
- 不要往 `GameEvents.cs` 加任何东西
- 不要改 `HUDController`——它的 `_emptyItemName = "空"` 已经能兜住空手
- 不要做背包扩容、快捷栏
- 不要新建文件

## 验收标准

Henry 场景里墙上摆着三件证据道具（各挂 `WorldItem`，
`Slot Index` 分别是 0/1/2），手电没有世界对象。

1. 编译通过，`git diff` 只有 `ItemSlotSystem.cs` 与 `WorldItem.cs`
2. 进 Play 点「开始游戏」：**手上拿着手电**，HUD 显示手电的名字
3. 按 T 收起手电，手上变空，HUD 显示「空」；再按 T 拿回来
4. 拿着手电时按 G **无反应**，手电不会掉在地上
5. 走到墙前瞄准 EMF：提示「[E] 捡起 EMF 读数器」，按 E 拿到手上
6. 转向旁边的紫外线灯：提示变成「**先放下手上的道具**」，
   按 E **完全没反应**，控制台不刷屏
7. 按 G 丢掉 EMF，再瞄准紫外线灯，提示恢复成「[E] 捡起 紫外线灯」，
   按 E 能拿起来
8. 手上拿着 EMF 时按 T 切到手电，此时再瞄准紫外线灯，
   提示**仍然是**「先放下手上的道具」——手电在手不代表编号槽空了
9. 按 F10 结束回合再开新一局：手上重新是手电，
   三件证据道具回到墙上原位
