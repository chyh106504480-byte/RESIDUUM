## 目标

进游戏先看到主菜单：标题、「开始游戏」、「退出」。点开始才进入回合。

**不开新场景**，做成当前场景里的一层覆盖画布。开第二个场景要重做导航
烘焙与灯光设置，还要处理场景加载时静态事件的坑，不值得。

## 要改两个文件

### 一、`Assets/_Project/Scripts/Core/GameManager.cs` —— 只加一个字段和一个判断

现在 `Start()` 无条件调 `StartRound()`，进 Play 就直接开局。加：

```csharp
[Tooltip("关闭后进 Play 不自动开局，等主菜单点「开始游戏」再调 StartRound")]
[SerializeField] private bool _autoStartOnPlay = true;
```

`Start()` 里 `_autoStartOnPlay` 为 false 时跳过 `StartRound()`。

**默认值保持 true**——没有主菜单的场景（比如测试台）行为不变。

`GameManager` 的其它任何一行都不许改。

### 二、`Assets/_Project/Scripts/UI/MainMenuUI.cs`（新建），命名空间 `Residuum.UI`

uGUI + TextMeshPro。所有界面引用 `[SerializeField]` 注入，
**不要在代码里创建任何 UI 对象**（搭建界面是下一个任务）。

```csharp
[SerializeField] private GameObject _panelRoot;
[SerializeField] private UnityEngine.UI.Image _backgroundImage;
[SerializeField] private TMPro.TextMeshProUGUI _titleLabel;
[SerializeField] private TMPro.TextMeshProUGUI _subtitleLabel;
[SerializeField] private UnityEngine.UI.Button _startButton;
[SerializeField] private UnityEngine.UI.Button _quitButton;

[Tooltip("标题文字")]
[SerializeField] private string _title = "残响";

[Tooltip("副标题")]
[SerializeField] private string _subtitle = "RESIDUUM";

[Tooltip("拖入玩家身上的 PlayerController 组件。菜单显示时禁用它")]
[SerializeField] private MonoBehaviour _playerControllerBehaviour;

[Tooltip("在 Inspector 里连到 GameManager.StartRound")]
public UnityEngine.Events.UnityEvent onStartRequested;
```

**背景图不由本组件设置。**`_backgroundImage` 的 `sprite` 由 Henry 自己在
Inspector 里拖——他会另外生成一张图。`_backgroundImage` 为空时跳过，
不报错。本组件只在开局时把 `_title` / `_subtitle` 写进两个标签。

行为：

- `Awake`：显示菜单（`_panelRoot.SetActive(true)`）、禁用
  `_playerControllerBehaviour`。**菜单是开局第一眼看到的东西，
  默认就该是显示状态**，和结算界面相反
- 「开始游戏」→ 隐藏菜单、恢复 `_playerControllerBehaviour`、
  `onStartRequested?.Invoke()`（顺序不能反，和结算界面同理）
- 「退出」→ `Application.Quit()`，并且在 `#if UNITY_EDITOR` 下
  额外设 `UnityEditor.EditorApplication.isPlaying = false`，
  否则编辑器里点退出没有任何反应，你会以为按钮坏了
- 订阅 `GameEvents.OnRoundStart`：回合真正开始时强制隐藏菜单
  （防止别处启动回合后菜单还挂在屏幕上）

**光标不要自己写。**禁用 `PlayerController` 时它的 `OnDisable` 会解锁光标，
恢复时 `OnEnable` 会按 `_lockCursorOnStart` 锁回去。和结算界面用同一套。

`_panelRoot` 不允许是本组件所在的 GameObject 或它的祖先，
`Awake` 里检出要报错并禁用组件。参照 `ResultScreenUI` 的同类校验。

## 验收标准

1. 编译通过，`git diff` 只有 `GameManager.cs`（一个字段一处判断）
   与新增的 `MainMenuUI.cs`
2. `GameManager._autoStartOnPlay` 取消勾选后进 Play：
   **主菜单直接显示**，鼠标光标可见，玩家不能移动，回合没有开始
   （HUD 的理智条不动、鬼不动）
3. 点「开始游戏」：菜单消失、光标锁定、玩家能动、回合开始
4. 玩一局撤离，结算面板弹出，点「再来一局」正常开新局，
   **主菜单不会再冒出来**
5. 点「退出」在编辑器里会停止 Play
6. `_backgroundImage` 不填图时菜单仍然可用，控制台无报错
7. `_autoStartOnPlay` 勾上时行为和改动前完全一致（直接开局，
   菜单若存在则被 `OnRoundStart` 隐藏）
8. 把 `_panelRoot` 拖成组件自己所在的物体，进 Play 时控制台报错，
   不抛空引用
