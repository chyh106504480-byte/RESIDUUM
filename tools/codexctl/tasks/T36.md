## 目标

`Residuum/搭建 HUD 与结算界面` 这个菜单再多建一套：主菜单画布，
并连好 `MainMenuUI` 的界面引用与 `onStartRequested`。

## 只改一个文件

`Assets/_Project/Scripts/UI/Editor/UISetupBuilder.cs`

**不要新增菜单项**，并进已有的 `Residuum/搭建 HUD 与结算界面`。

字段名请**直接读 `Assets/_Project/Scripts/UI/MainMenuUI.cs` 确认**，
不要凭这份任务书猜。

## 要建的层级

根节点名 `Main Menu Canvas`，沿用已有的 `GetOrCreateRootCanvas` +
`ConfigureCanvas`：

- `sortingOrder = 200`。**必须是全场最高**：主菜单在最上层，
  它显示的时候 HUD（0）、笔记本（50）、撤离弹窗（80）、
  结算（100）都该被盖住
- 挂 `Residuum.UI.MainMenuUI`

子节点：

| 子节点 | 类型 | 说明 | 连到 |
|---|---|---|---|
| `Panel` | `Image` | 铺满全屏，**不透明**的近黑色（这是主菜单不是弹窗，不该透出场景） | `_panelRoot` |
| `Panel/Background` | `Image` | 铺满全屏，白色、`sprite` 留空 | `_backgroundImage` |
| `Panel/Title` | `TextMeshProUGUI` | 上部居中，字号 96，居中对齐 | `_titleLabel` |
| `Panel/Subtitle` | `TextMeshProUGUI` | `Title` 下方，字号 28，居中 | `_subtitleLabel` |
| `Panel/StartButton` | `Button` + 子 `TextMeshProUGUI` | 下部居中，280×64，文字「开始游戏」 | `_startButton` |
| `Panel/QuitButton` | `Button` + 子 `TextMeshProUGUI` | `StartButton` 下方 20px，280×64，文字「退出」 | `_quitButton` |

顺序要求：`Background` 必须是 `Panel` 的**第一个子节点**，
排在标题和按钮之前，否则背景图会盖住它们。

`Background` 的 `sprite` **留空**——Henry 会自己生成一张图拖进来。
`sprite` 为空时 Unity 的 `Image` 会渲染成一块纯白，
所以把它的 `color` 设成近黑 `(0.06, 0.06, 0.07, 1)`，
这样不填图时是一块深色底而不是刺眼的白。

`Background` 的 `raycastTarget` 要关掉，别挡住按钮。

**`_panelRoot` 必须连 `Panel`，不能连画布本身**——`MainMenuUI` 挂在
画布上、必须保持启用才收得到 `OnRoundStart`。

**`Panel` 建完保持激活。**主菜单和其它面板相反，它是开局第一眼看到的
东西，默认就该显示。

## 连线

用已有的 `UnityEventTools` 辅助方法：

- `MainMenuUI.onStartRequested` → 场景里 `GameManager` 的 `StartRound`
- `MainMenuUI._playerControllerBehaviour` → 场景里的 `PlayerController`

连之前先清同名旧监听。场景里找不到 `GameManager` 或 `PlayerController`
就 `Debug.LogWarning` 点名，**不要中止**。

## 完成日志里多说一句

建完提醒 Henry：**要让主菜单真正生效，得把 `GameManager` 的
`Auto Start On Play` 取消勾选**，否则进 Play 会直接开局、
菜单一闪而过。这一条工具改不了（那是场景数据，不该由搭建工具替他决定）。

## 明确不要做的

- 不要改 `MainMenuUI.cs`、`GameManager.cs` 或任何运行时脚本
- 不要新增菜单项
- 不要动已有的 HUD、结算、笔记本、撤离弹窗四套的搭建逻辑
- 不要自动改 `GameManager._autoStartOnPlay`
- 不要引入或生成任何图片资源
- 不要自动保存场景
- 不要做圆角、渐变、动画

## 验收标准

1. 编译通过，`git diff` 只有 `UISetupBuilder.cs` 一个文件
2. 跑菜单，Hierarchy 里多出 `Main Menu Canvas`，`Panel` 是**激活**状态
3. `MainMenuUI` 上四个界面引用与 `_backgroundImage` 全部非空，
   `_panelRoot` 指向 `Panel`
4. `onStartRequested` 有**恰好一条**持久监听指向
   `GameManager.StartRound`；连跑三次仍然只有一条
5. `_playerControllerBehaviour` 指向场景里的 PlayerController
6. 选中 `Main Menu Canvas` 下任意子物体，`Scale` 是 `1, 1, 1`
7. 取消勾选 `GameManager.Auto Start On Play`，进 Play：
   主菜单占满屏幕、看不到场景、光标可见、玩家不能动
8. 点「开始游戏」，菜单消失、回合开始、光标锁定
9. 不填背景图时菜单是深色底，不是刺眼的纯白
10. 控制台最后一条日志提到了要取消勾选 `Auto Start On Play`
