## 症状（阻断级）

**鬼的视线能穿透所有墙和地板。**玩家躲到楼下、隔壁房间都没用，
鬼永远锁定你，「切断视线甩掉它」这个核心逃生手段完全失效。

## 根因

`ColliderBuilder`（`Assets/_Project/Scripts/World/Editor/ColliderBuilder.cs`
约 77 行）有这条跳过规则：

```csharp
if (HasRoomVolumeOnSelfOrAncestor(targetObject.transform))
{
    skippedRoomVolumeCount++;
    continue;
}
```

场景里八个 `BLK_*` 房间物体上都挂着 `RoomVolume`（鬼房检测用）。
墙体与楼板都是这些物体的**子孙**，于是
`HasRoomVolumeOnSelfOrAncestor` 全部命中，**整栋楼一个碰撞体都没加**。

`GhostAI` 的视线检测用 `Physics.Linecast` + `Default` 层遮罩，
没有碰撞体自然什么都挡不住。

这条规则的本意是「别给房间检测体本身加碰撞体，那会挡住玩家」，
但它误伤了房间下面的全部几何。

## 只改一个文件

`Assets/_Project/Scripts/World/Editor/ColliderBuilder.cs`

## 改法

把判断从「**自己或任何祖先**挂着 RoomVolume」缩小成
「**只有自己**挂着 RoomVolume」。

```csharp
// 只跳过 RoomVolume 所在的那个物体本身。房间检测体是个大盒子，
// 给它加碰撞体会挡住玩家；但它下面的墙体与楼板必须有碰撞体，
// 否则鬼的视线检测穿透一切。
if (targetObject.GetComponent<Residuum.World.RoomVolume>() != null)
{
    skippedRoomVolumeCount++;
    continue;
}
```

`HasRoomVolumeOnSelfOrAncestor` 这个方法如果没有别的调用方就删掉，
有的话保留但本处不再使用。

统计与日志照旧，`skippedRoomVolumeCount` 的含义变成
「跳过的 RoomVolume 物体本身数量」。

## 其余跳过规则一律不动

- `skippedMissingMeshCount`（没有 sharedMesh）
- `skippedKeywordCount`（名字含排除关键字）
- `skippedExistingColliderCount`（已有 Collider）

这三条保持原样。

## 明确不要做的

- 不要改 `GhostAI.cs`、`RoomVolume.cs`、`RoomManager.cs`
- 不要改移除碰撞体那个菜单命令的逻辑
- 不要改视线检测、遮罩、任何运行时脚本
- 不要自动给场景加碰撞体（仍然只处理 Selection 选中的物体）
- 不要新建文件

## 验收标准

Henry 会在 Hierarchy 里选中八个 `BLK_*` 房间物体，跑
`Residuum/为选中对象批量加碰撞体`。

1. 编译通过，`git diff` 只有 `ColliderBuilder.cs` 一个文件
2. 跑完控制台报**加了几百个** MeshCollider，不再是「0 个，全部跳过」
3. `BLK_*` 物体**自身**仍然没有被加碰撞体
   （它们挂着 `RoomVolume`，加了会挡住玩家）
4. 进 Play，玩家不会穿墙、不会掉出地板
5. 按 P 强制猎杀，玩家躲到墙后或楼下：
   **鬼失去目标**，Scene 视图里的视线红线被墙挡住，
   鬼会去最后消失点附近搜索而不是直冲玩家
6. 鬼仍然能正常寻路、开门、追击视野内的玩家
7. 再跑一次同一个菜单，报「全部跳过（已有碰撞体）」，不会重复添加
