## 目标

三件事：

1. **EMF 读数器加开关**——左键开机/关机，关机时不读数、不响
2. **开机后持续发出滴滴声**，读数越高滴得越快
3. **HUD 显示状态**：没拿 → 不显示；拿着关机 → `EMF  OFF`；
   拿着开机 → `EMF  3`

紫外线灯的左键开关**已经有了**（`UVLight.OnPrimaryUse`），
本任务照它的写法给 EMF 补上。

## 契约的三个取值（已由总控写进 GameEvents 注释，不要改那个文件）

`GameEvents.OnEMFReadingChanged(int)`：

| 值 | 含义 | HUD 表现 |
|---|---|---|
| `-1` | 没拿在手上 | 整个显示隐藏 |
| `-2` | 拿着但关机 | 显示 `EMF  OFF` |
| `0`–`5` | 开机中的读数 | 显示 `EMF  3` |

## 要改三个文件

### 一、`Assets/_Project/Scripts/Evidence/EMFReader.cs`

**开关：**

`OnPrimaryUse()` 现在是空实现。改成翻转一个 `_isPoweredOn` 标志。

- 装备时（`OnEquip`）默认**开机**——玩家拿出来就是要用的
- 关机时：停止读数（走现有的 `StopReading()`）、停止滴声、
  广播 `RaiseEMFReadingChanged(-2)`
- 开机时：恢复读数检测、恢复滴声、广播当前读数
- 收起时（`OnUnequip`）：广播 `RaiseEMFReadingChanged(-1)`

现有的 `SetReading(int)` 开头有 `if (Reading == level) return;` 的去重。
**广播 -1 / -2 不要走它**，否则收起再拿出来、或反复开关时不会重新广播。

关机状态下 `HandleGhostInteract` 直接返回，不累积读数。

**滴滴声：**

```csharp
[Header("音效")]
[Tooltip("滴滴声的音源。建议挂在读数器手持模型上，Spatial Blend 设 0")]
[SerializeField] private AudioSource _beepSource;

[Tooltip("单次滴声")]
[SerializeField] private AudioClip _beepClip;

[Range(0f, 1f)]
[SerializeField] private float _beepVolume = 0.7f;

[Tooltip("读数为 0 时两次滴声的间隔秒数")]
[Min(0.05f)]
[SerializeField] private float _beepIntervalAtZero = 1.5f;

[Tooltip("读数为 5 时两次滴声的间隔秒数")]
[Min(0.02f)]
[SerializeField] private float _beepIntervalAtMax = 0.12f;
```

- **只在「装备中 且 开机」时响**
- 间隔按当前读数在两个值之间线性插值，读数变化立刻生效，
  不要等当前这一拍走完
- `PlayOneShot(_beepClip, _beepVolume)`，不要用 `Play()`
- 音源或 clip 为 null 时静默跳过，不报错不打警告

`EMFReader` 的检测半径、读数计算、`GhostHasEMF5` 那道封顶闸
**一行都不许改**。

## 验收标准

1. 编译通过，`git diff` 只有 `EMFReader.cs`、`HUDController.cs`、
   `UISetupBuilder.cs` 三个文件
2. 跑 `Residuum/搭建 HUD 与结算界面`，`HUD Canvas` 下出现 `EMFLabel`，
   建完未激活，`HUDController._emfLabel` 已连好
3. 进 Play，手上没拿读数器时 HUD **不显示** EMF 那一行
4. 拿出读数器：显示 `EMF  0`，**开始慢速滴滴**
5. 按左键关机：显示变成 `EMF  OFF` 且变灰，**滴声停止**，
   靠近鬼读数也不再变化
6. 再按左键开机：恢复显示读数与滴声
7. 走近鬼读数升高，滴声明显变快，3–4 变琥珀色、5 变红色
8. 按 T 切到手电（收起读数器）：EMF 那一行**整个消失**，滴声停
9. 切回读数器，显示与滴声恢复，且**保持切走之前的开关状态**
10. 不填音源或不填 `_emfLabel` 时一切照常，控制台无报错
