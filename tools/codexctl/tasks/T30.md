## 目标

`AudioDirector` 现在的触发时机是我按猜测排的，Henry 定的实际设计是：

| 音效 | 什么时候响 |
|---|---|
| 恐怖的哈气声 | **巡逻阶段小概率**随机触发；**鬼现身结束之后中概率**触发 |
| 鬼笑低语 | 猎杀开始（**现在就是对的，别动**） |
| 喘气声 | **玩家冲刺体力耗尽的那一刻** |
| 加速心跳声 | 按鬼的距离缩放（**现在就是对的，别动**） |

## 契约已就位

```csharp
/// 玩家冲刺体力耗尽的那一刻
public static event Action GameEvents.OnStaminaDepleted;
public static void GameEvents.RaiseStaminaDepleted();
```

**不要自己往 GameEvents.cs 加任何东西。**

## 要改两个文件

### 一、`Assets/_Project/Scripts/Player/PlayerController.cs` —— 只加一行

`PlayerController.cs:555-559` 这一段：

```csharp
CurrentStamina = Mathf.Max(0f, CurrentStamina - deltaTime * drainMultiplier);
if (CurrentStamina <= Mathf.Epsilon)
{
    CurrentStamina = 0f;
    _sprintLockedUntilFull = true;
}
```

`_sprintLockedUntilFull = true;` 这一行就是「冲刺结束」的确切时刻。
在它旁边广播 `GameEvents.RaiseStaminaDepleted()`。

**只在从「未锁」变成「已锁」的那一次广播**，不要每帧都发——
这个分支在体力为 0 时可能被反复进入。进来前先看 `_sprintLockedUntilFull`
本来是不是 false。

`PlayerController` 的其它任何一行都不许改。

### 二、`Assets/_Project/Scripts/Audio/AudioDirector.cs`

#### 喘气声改接体力耗尽

现在 `_sanityCriticalClip` 接的是 `OnSanityCritical`。把喘气声这一路
改名并改接 `OnStaminaDepleted`：

- 新增 `_staminaDepletedClip` 与 `_staminaDepletedVolume`
- **`_sanityCriticalClip` 那一路保留不动**，将来还会用，只是现在没素材

#### 哈气声改成两个触发点

现在 `_ghostManifestClip` 接的是 `OnGhostEvent`（现身瞬间）。改成：

```csharp
[Header("哈气声")]
[Tooltip("巡逻阶段随机哈气声的判定间隔秒数")]
[Min(1f)]
[SerializeField] private float _ambientBreathCheckInterval = 25f;

[Tooltip("巡逻阶段每次判定触发的概率，应当很小")]
[Range(0f, 1f)]
[SerializeField] private float _ambientBreathChance = 0.15f;

[Tooltip("鬼现身结束后触发哈气声的概率，应当中等")]
[Range(0f, 1f)]
[SerializeField] private float _postManifestBreathChance = 0.5f;

[Tooltip("鬼现身开始到现身结束的秒数，应与 GhostAI 的显形秒数一致")]
[Min(0f)]
[SerializeField] private float _manifestDuration = 2f;
```

行为：

- **巡逻阶段**：回合进行中、**没有在猎杀**、鬼**没有正在现身**时，
  每 `_ambientBreathCheckInterval` 秒滚一次 `_ambientBreathChance`，
  命中就播哈气声
- **现身结束后**：收到 `OnGhostEvent` 后等 `_manifestDuration` 秒，
  然后滚一次 `_postManifestBreathChance`，命中就播
- **现身的那一瞬间不再播哈气声**——按 Henry 的设计，哈气是「之前」和
  「之后」的铺垫，不是现身本身的音效

现身期间不要让巡逻的周期判定命中，否则两个哈气声会叠在一起。

#### 回合边界

`OnRoundStart` / `OnRoundEnd` 时把巡逻判定计时与「现身后待触发」的
挂起状态一并清掉，别让上一局的挂起延续到下一局。

## 验收标准

1. 编译通过，`git diff` 只有 `PlayerController.cs` 与 `AudioDirector.cs`
2. 按住 Shift 一路冲刺到体力耗尽，**那一刻**听到喘气声；
   继续按着 Shift 不放，喘气声**不会连续重复播放**
3. 体力回满后再冲刺到耗尽，喘气声再响一次
4. 把 `_ambientBreathCheckInterval` 临时调成 3 秒、`_ambientBreathChance`
   调成 1，进 Play 后每 3 秒听到一次哈气声
5. 按 P 进入猎杀，巡逻哈气声**停止**（猎杀期间不播）
6. 把 `GhostAI._manifestChance` 调成 1、`_manifestCheckInterval` 调成 5 秒，
   `_postManifestBreathChance` 调成 1：鬼现身那一刻**没有**哈气声，
   现身结束（2 秒后）才响
7. 猎杀开始时仍然播鬼笑低语
8. 心跳的表现和改动前完全一致
9. 按 F10 结束回合再开新一局，不会突然冒出上一局挂起的哈气声
