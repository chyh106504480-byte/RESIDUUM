## 目标

给摆在大堂的四件道具挂上「按 E 捡起」的能力。

## 只做一个文件

`Assets/_Project/Scripts/Items/WorldItem.cs`，命名空间 `Residuum.Items`，
实现 `Residuum.Core.IInteractable`。

## 契约与依赖

`ItemSlotSystem`（T31 已完成）提供：

```csharp
public bool TryPickUpSlot(int index)    // index 为 0/1/2
public bool TryPickUpFlashlight()
```

`WorldItem` 与 `ItemSlotSystem` **同属 `Residuum.Items`**，
直接引用类型不算跨模块，不需要新事件也不需要 UnityEvent 连线。

字段名与签名请**直接读
`Assets/_Project/Scripts/Items/ItemSlotSystem.cs` 确认**，
不要凭这份任务书猜。

## 要做的东西

```csharp
[Tooltip("这件道具对应哪个编号槽。勾上「是手电筒」时本字段忽略")]
[Range(0, 2)]
[SerializeField] private int _slotIndex;

[Tooltip("勾上表示这是手电筒，走独立的拾取路径")]
[SerializeField] private bool _isFlashlight;

[Tooltip("道具的中文名，用于交互提示")]
[SerializeField] private string _itemName = "道具";

[Tooltip("提示文本模板，{0} 会被替换成道具名")]
[SerializeField] private string _promptFormat = "[E] 捡起 {0}";
```

- `PromptText` —— `string.Format(_promptFormat, _itemName)`
- `CanInteract` —— 恒为 true（拿不拿得动由 `ItemSlotSystem` 判断）
- `Interact(GameObject interactor)`：
  1. 从 `interactor` 上取 `ItemSlotSystem`，用
     `GetComponentInChildren<ItemSlotSystem>()`——它可能挂在玩家根节点，
     也可能在子节点
  2. 取不到就 `Debug.LogWarning` 说明在交互者身上找不到物品栏，然后返回
  3. `_isFlashlight` 为真调 `TryPickUpFlashlight()`，否则调
     `TryPickUpSlot(_slotIndex)`
  4. 返回 false（已经持有了）时什么都不做，**不要报错刷屏**——
     玩家对着一个已经拿过的道具按 E 是正常操作

**不要在 `Interact` 里自己 `SetActive(false)`。**隐藏世界对象是
`ItemSlotSystem` 的职责，两边都做会打架，而且丢弃时它还要负责把对象
移回来显示。

## Awake 校验

- `_isFlashlight` 为假且 `_slotIndex` 不在 0–2 之间 → `Debug.LogError`
  点名这个物体
- 场景里挂着 `WorldItem` 的物体**必须有碰撞体**，没有的话
  `Debug.LogWarning` 提醒——准星打不到就等于这件道具永远捡不起来，
  而且不报任何错，极难发现

## 明确不要做的

- 不要改 `ItemSlotSystem`、`Flashlight`、三件证据道具
- 不要往 `GameEvents.cs` 加任何东西
- 不要做拾取音效、动画、高亮描边
- 不要做「按住 E 拾取」这类长按机制
- 不要自己隐藏或移动世界对象
- 不要新建编辑器脚本或预制体

## 需要新事件怎么办

不要自己加。写在最终回复里说明签名与理由。本任务预期不需要。

## 验收标准

Henry 会在大堂放一张桌子，把四件道具摆上去，各挂 `WorldItem`：

1. 编译通过，`git diff` 只有新增的 `WorldItem.cs`（及其 meta）
2. 进 Play 手上是空的，走到大堂瞄准某件道具，
   准星下方出现「[E] 捡起 EMF 读数器」
3. 按 E，道具出现在手上，桌上那件消失，HUD 物品名跟着变
4. 按 G 丢在地上，走过去瞄准它，提示照常出现，按 E 能再捡起来
5. 四件都捡起来后，三个编号槽用 1/2/3 切换，手电用 T
6. 对着一件已经拿在手上的道具按 E，什么都不发生，控制台不刷屏
7. 把某个 `WorldItem` 的 `_slotIndex` 填成 5，进 Play 时控制台报错点名它
8. 去掉某件道具的碰撞体，进 Play 时控制台出现提醒该物体没有碰撞体的警告
9. 按 F10 结束回合再开新一局，四件道具回到桌上
