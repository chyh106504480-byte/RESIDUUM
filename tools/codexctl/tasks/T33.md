## 目标

猎杀期间**全场灯光变成红色**并继续闪烁，猎杀结束后恢复原色。

红色必须来自**灯本身**，不是屏幕上糊一层红膜。屏幕那层红（HUD 的
`HuntVignette`）由 Henry 在 Inspector 里取消勾选 `Show Hunt Vignette`
关掉，**本任务不改 `HUDController`**。

## 只改一个文件

`Assets/_Project/Scripts/World/LightManager.cs`

## 现状

`LightManager` 现在只在**鬼现身**时染红（`_manifestColor` +
`CaptureManifestLightStates` / `RestoreManifestLightStates`，
颜色与开关状态都会快照并还原）。

**猎杀闪烁只改 `enabled`，不改颜色**——`CaptureLightStates` 存的是
`bool[]`，没有颜色。本任务把颜色也纳进来。

## 要做的事

### 一、猎杀闪烁加上红色

```csharp
[Tooltip("猎杀期间的灯光颜色")]
[SerializeField] private Color _huntColor = new Color(0.85f, 0.1f, 0.1f, 1f);
```

`StartFlicker` 之前的快照要**同时记录 `color` 和 `enabled`**，
闪烁过程中每盏灯的 `color` 设为 `_huntColor`、`enabled` 按原有的
`_flickerOnChance` 随机；`StopFlicker(true)` 时**颜色和开关都还原**。

现有的「恢复到猎杀前的状态」这条保证不能破坏——玩家猎杀前特意关掉的灯，
猎杀结束后依然是关着的，而且是原来的颜色。

### 二、别把两套快照搞混

现在有两套独立的快照：现身用的
（`_lightStatesBeforeManifest` / `_lightColorsBeforeManifest`）和
闪烁用的（`_lightStatesBeforeFlicker`）。

**闪烁那套要补上颜色数组**，但两套仍然各存各的。

`HandleHuntStart` 里已有的 `StopManifestEffect(true)` 调用**必须保留在
拍闪烁快照之前**——先把现身染的红还原回原色，再拍快照。
顺序反了的话，闪烁快照会把「现身的红」当成原色存下来，
猎杀结束后灯就永远是红的了。

### 三、猎杀停电那一支不受影响

`_huntBlackoutChance` 命中时走 `BeginBlackout(false)`，全场熄灭。
熄灭的灯没有颜色可言，**不要在这一支里染红**。
`BeginBlackout` 里已有的 `StopFlicker(true)` / `StopManifestEffect(true)`
保持不变。

### 四、优先级不变

```
停电 > 猎杀红光闪烁 > 现身红光
```

停电期间不闪烁、不染色；猎杀期间忽略现身效果。这些现有判断别动。

## 明确不要做的

- **不要改 `HUDController`**——屏幕暗角由 Henry 自己在 Inspector 关
- 不要生成任何贴图、Sprite、材质
- 不要碰 `Light.intensity`、`range`、阴影设置，只改 `color` 与 `enabled`
- 不要改 `_manifestColor` 或现身那一整套逻辑
- 不要改随机停电的参数与行为
- 不要往 `GameEvents.cs` 加任何东西
- 不要新建文件

## 验收标准

1. 编译通过，`git diff` 只有 `LightManager.cs` 一个文件
2. 把 `_huntBlackoutChance` 临时调成 0，按 P 猎杀：
   **全场灯变红并闪烁**，屏幕本身没有红膜
   （前提是 Henry 已经取消勾选 `Show Hunt Vignette`）
3. 猎杀结束后灯**恢复成原来的白色**，不残留红色
4. 猎杀前手动关掉某一盏灯，猎杀结束后**那一盏依然是关着的、且是白色**
5. 连打五次猎杀，灯色始终能回到最初的白色，不会越来越红
   （这条验闪烁快照没有把红色当成原色存下来）
6. 让鬼现身（`GhostAI._manifestChance` 调成 1）后**紧接着**按 P 猎杀，
   猎杀结束后灯仍然回到白色——这条专门验
   `StopManifestEffect` 与拍快照的先后顺序
7. `_huntBlackoutChance` 调成 1 时按 P，全场熄灭，不染红
8. 停电期间按 P 猎杀，灯不会亮起来变红
