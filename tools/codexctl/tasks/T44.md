## 症状

把鬼影书放到地上后，只要切换到别的道具，**地上的书就凭空消失**，
再也找不到、捡不回来。鬼影书这项证据因此无法采集。

## 根因

`GhostWritingBook.OnPrimaryUse` 放置时会
`transform.SetParent(null, true)` 让自己脱离手持挂点，留在地上——
**这是设计如此**，书要留在原地等鬼写字。

但 `ItemSlotSystem` 的 `Held Models` 数组仍然指着同一个物体。
收起道具时它照常 `SetActive(false)`，把已经在地上的书一起隐藏了。

两个组件都没错，是「手持模型」和「世界中的书」恰好是同一个物体，
而 `ItemSlotSystem` 不知道它已经离开了手。

## 只改一个文件

`Assets/_Project/Scripts/Items/ItemSlotSystem.cs`

## 改法

找到负责开关手持模型的方法（约 `SetHeldModelActive`）。

**在把某个手持模型设为不可见之前，先检查它是不是还挂在
`_handAnchor` 下面。已经不在了就跳过这次隐藏。**

判断用纯 Transform 关系即可：

```csharp
// 已经脱离手持挂点的模型（例如放到地上的鬼影书）不归物品栏管显隐
if (!model.transform.IsChildOf(_handAnchor))
{
    return;
}
```

**只跳过「隐藏」这一侧。**显示那一侧（`SetActive(true)`）保持原样——
玩家把书捡回来时，`GhostWritingBook.RestoreHeldPose()` 会先把它挂回
`_handAnchor`，那时候这个判断自然成立，照常显示。

`_handAnchor` 为 null 时按原有逻辑走，不要因为这个判断报错。

**不要引用 `Residuum.Evidence` 的任何类型**——不需要知道它是不是
鬼影书，只需要知道它还在不在手上。

## 验收标准

1. 编译通过，`git diff` 只有 `ItemSlotSystem.cs` 一个文件
2. 进 Play 捡起鬼影书，按 `3` 装备，**手上能看见书**
3. 低头对着地面按左键，书落到地上，人不动
4. 按 `1` 切到 EMF：**地上的书仍然在**，不会消失
5. 走过去瞄准地上的书，出现拾取提示，按 E 能捡回来，
   捡回来后按 `3` 手上又能看见
6. EMF 与紫外线灯的手持模型显隐**行为完全不变**——
   切走消失、切回出现
