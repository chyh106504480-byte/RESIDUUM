## 目标

三格道具槽 + 第一件道具手电筒。手电筒是本作最重要的道具，
它同时是主光源、理智缓冲和猎杀期的恐惧放大器。

## 契约（已存在，不许改）

先读，按现有签名实现，不要凭印象猜：

```
Assets/_Project/Scripts/Items/IHoldable.cs   // ItemName / OnEquip / OnUnequip / OnPrimaryUse
Assets/_Project/Scripts/Core/GameEvents.cs
```

本任务需要的事件**已经加进契约、可以直接用**：

```csharp
// 当前装备槽变化。参数：槽位索引 0-2；物品中文名（空槽传 null）。HUD（T14）订阅。
GameEvents.RaiseSlotChanged(int slotIndex, string itemName);

// 手电筒电量变化。参数：归一化电量 0–1。HUD（T14）订阅。
GameEvents.RaiseBatteryChanged(float normalized);

// 已有的，直接订阅：
GameEvents.OnHuntStart(float duration) / OnHuntEnd / OnGhostEvent(Vector3)
```

**注意**：不要在 `ItemSlotSystem` 或 `Flashlight` 上声明自己的 `public event`
给 UI 用。UI 只订阅事件总线，不认识你的类。

## 要做的文件

### 1. `Assets/_Project/Scripts/Items/ItemSlotSystem.cs`

命名空间 `Residuum.Items`，挂在玩家身上。

- `[SerializeField] private MonoBehaviour[] _slots`（长度 3）
  —— **不要**用 `IHoldable[]`，Unity 不能序列化接口数组。
  在 `Awake` 里把每个元素 `as IHoldable`，转换失败的槽位 `Debug.LogError`
  指出是第几槽，并把该槽当空槽处理，**不要抛异常**
- `[SerializeField] private Transform _handAnchor`（手持模型挂点），
  为空时 `Debug.LogError` 并禁用组件
- `[SerializeField] private UnityEngine.InputSystem.InputActionAsset _inputActions`
  —— 用工程现有的 `Assets/InputSystem_Actions.inputactions`，**不要新建输入资产**。
  数字键 1/2/3 与滚轮切换、左键使用，都从这个资产里取 action
- 切换时：先调用上一件的 `OnUnequip()`，再调用新一件的 `OnEquip()`；
  未装备的手持模型隐藏（`SetActive(false)`），装备的显示
- 切到当前已装备的槽位时**不要**重复触发 Unequip/Equip
- 每次切换调用 `GameEvents.RaiseSlotChanged(index, 物品名)`
- 左键调用 `Current.OnPrimaryUse()`
- `public IHoldable Current { get; private set; }`
- 事件订阅 / action 启用在 `OnEnable`，退订 / 禁用在 `OnDisable`，严格配对

### 2. `Assets/_Project/Scripts/Items/Flashlight.cs`

命名空间 `Residuum.Items`，实现 `IHoldable`。

- `[SerializeField] private Light _spotLight`（子物体上的 URP Spot Light），
  为空时 `Debug.LogError`
- 光照参数全部 `[SerializeField]` + 中文 `[Tooltip]`：
  强度、色温默认 `4200`、射程默认 `12`、内锥角默认 `30`、外锥角默认 `45`
- 电量：`[SerializeField]` 满电秒数默认 `300`；开启时消耗；
  每次变化调用 `GameEvents.RaiseBatteryChanged(0–1)`，
  **只在变化超过可调阈值（默认 `0.01`）时才广播**，不要每帧刷
- 低电量：`[SerializeField]` 阈值默认 `0.2`，低于时随机闪烁，频率随电量下降而升高
- 耗尽：自动关闭并进入 `[SerializeField]` 冷却秒数默认 `15`，期间无法开启
- `OnPrimaryUse()` 切换开关；F 键**即使未装备也能开关**（它是主光源），
  F 键同样从注入的 InputActionAsset 里取
- 订阅 `GameEvents.OnHuntStart`：立即进入强制故障，协程做不规则闪烁
  （随机间隔 `[SerializeField]` 默认 `0.05`–`0.4` 秒），期间无法手动控制
- 订阅 `GameEvents.OnHuntEnd`：恢复正常
- 订阅 `GameEvents.OnGhostEvent`：位置在 `[SerializeField]` 距离内（默认 `8` 米）时，
  触发 `[SerializeField]` 时长（默认 `1.5` 秒）的短暂闪烁
- `public void ForceOff(bool locked)`：强制熄灭并锁定，锁定期间 F 无效。
  这是留给紫外线灯的互斥接口（紫外荧光只在黑暗中可见），
  **由 Inspector 的 UnityEvent 连线触发，两个道具之间不直接引用**
- **协程缓存 `WaitForSeconds`**，不要在循环里 `new`；
  所有协程在 `OnDisable` 中停止

## 明确不要做的

- **不要做紫外线灯、EMF、鬼影书** —— 那是 T05 / T06 / T07，
  你只留 `ForceOff` 这个接口给它们
- **不要做电池拾取 / 补给** —— 不在切片范围
- **不要做手电筒 UI** —— 那是 T14，你只负责广播
- **不要做手电筒音效** —— 那是 T17
- **不要**引用 `Residuum.World`、`Residuum.Ghost`、`Residuum.Player` 的任何具体类
- **不要新建 InputActionAsset**，用工程现有的那个
- 只产出上面两个文件

## 需要新事件怎么办

本任务要的事件已经就位。如果你认为还缺，**不要自己加**，在最终回复里写清楚：
事件名、参数签名、什么时候触发、为什么现有事件表达不了。由人类统一加进契约文件。

## 验收标准

- 数字键 1/2/3 与滚轮都能切换三个槽，切换时上一件收起、新一件出现
- 切到当前已装备的槽位不会重复触发 Equip/Unequip
- 手电筒 F 键开关正常，未装备时 F 也有效
- 电量耗尽后自动熄灭，15 秒内按 F 无反应，之后恢复
- 手动触发 `GameEvents.RaiseHuntStart(20f)`，手电筒立刻疯狂不规则闪烁，
  期间 F 键无效；`RaiseHuntEnd()` 后恢复
- 两个文件除 UnityEngine / UnityEngine.InputSystem / System 外，
  只允许 `using Residuum.Core;`
- 所有数值 `[SerializeField]` + 中文 `[Tooltip]`，零硬编码魔法数
- 编译零错误
